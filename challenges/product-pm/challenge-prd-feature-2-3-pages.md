# Challenge: Viết PRD 2–3 Trang cho 1 Feature

- **Loại:** project (tài liệu)
- **Mảng:** product-pm
- **Mức:** Beginner
- **Ước lượng thời gian:** 0.5-1 ngày
- **Prerequisites (tùy chọn):** Hiểu căn bản về PRD, user story, metric.

## Mục tiêu học tập
- Viết PRD ngắn gọn, rõ scope và acceptance.
- Xác định người dùng, vấn đề, KPI/metric đo lường.

## Đề bài
Chọn một feature cụ thể (ví dụ: “Saved Items” cho e-commerce) và viết PRD 2–3 trang gồm:
- Context & Problem statement.
- Persona / user stories.
- Scope: in-scope vs out-of-scope.
- Acceptance criteria.
- Metric/KPI & success definition.
- Risk & assumption.

## Đầu vào (Input)
- Mô tả ngắn về sản phẩm/đối tượng người dùng (bạn tự chọn nếu chưa có).

## Đầu ra (Output)
- File markdown 2–3 trang PRD đầy đủ các mục trên.

## Tiêu chí chấm (Acceptance)
- **Rõ ràng:** Bám sát vấn đề, không lan man; in/out-of-scope tách bạch.
- **Đo lường:** Có metric/KPI và cách đo; acceptance criteria cụ thể.
- **Thực tế:** Có risk/assumption và cách giảm thiểu.

## Gợi ý / Hint
- Dùng user story format: As a …, I want …, so that …
- Metrics: activation, conversion, retention, task success rate.

## Reference solution (tùy chọn)
- (Tuỳ chọn) Đính kèm PRD mẫu nếu public.
