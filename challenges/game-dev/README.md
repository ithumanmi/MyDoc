# Game Dev Challenges

Gameplay, engine, performance, tooling.

- Copy `../template.md` → `challenge-<slug>.md`.

### Gợi ý chủ đề
- Prototype gameplay loop + cảm giác điều khiển.
- ECS/architecture: tách logic/render, data-oriented.
- Performance: profiling, batching, asset pipeline.
- Networking (tùy chọn): sync state, lag compensation.
