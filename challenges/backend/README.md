# Backend Challenges

Challenge về API, system design, performance, reliability.

- Copy `../template.md` để tạo challenge.
- Đặt tên: `challenge-<slug>.md`.

### 🗺️ Lộ trình gợi ý
- **Beginner:** CRUD API + auth cơ bản + pagination.
- **Intermediate:** CQRS + outbox + idempotency + cache.
- **Advanced:** High-load, profiling + observability, failure injection.

### 🧭 Liên kết học trước (prereq)
- Domain: [`domains/backend-dev/README.md`](../../domains/backend-dev/README.md)
- Guides: testing, time-management (deep work), system design.

### 📌 Gợi ý chủ đề
- REST/gRPC API với auth, rate limit, pagination.
- Cache + CQRS + outbox + idempotency.
- Scaling: load test, profiling, connection pool.
- Observability: metrics, tracing, alerting.
