# Backend Challenges

Challenge về API, system design, performance, reliability.

- Copy `../template.md` để tạo challenge.
- Đặt tên: `challenge-<slug>.md`.

### Gợi ý chủ đề
- REST/gRPC API với auth, rate limit, pagination.
- Cache + CQRS + outbox + idempotency.
- Scaling: load test, profiling, connection pool.
- Observability: metrics, tracing, alerting.
