# 📂 Data Analytics Portfolio Checklist

> [← Back to Data Analytics Roadmap](../README.md)

Để xin được việc, bạn cần 3-5 dự án chất lượng (Quality > Quantity). Đừng chỉ up code lên GitHub, hãy viết Case Study.

---

## 1. Cấu trúc một Case Study chuẩn 📝
Mỗi dự án trong Portfolio cần trả lời được các câu hỏi sau:

*   **Business Problem:** Bạn đang giải quyết vấn đề gì? (VD: Doanh số giảm, Khách hàng rời bỏ).
*   **Data Source:** Dữ liệu lấy ở đâu? (Kaggle, Mockaroo, Web scraping).
*   **Process (Quy trình):**
    *   Cleaning: Bạn làm sạch dữ liệu thế nào? (Xử lý null, duplicate).
    *   Analysis: Bạn dùng kỹ thuật gì? (SQL, Python).
*   **Visualizations:** Ảnh chụp Dashboard/Biểu đồ.
*   **Insights & Recommendations:** Kết luận là gì? Đề xuất hành động gì cho doanh nghiệp?

---

## 2. Các ý tưởng dự án (Project Ideas) 💡

### Dự án 1: Excel Dashboard (Cơ bản)
*   [ ] Tải dữ liệu bán hàng (Sales Data).
*   [ ] Làm sạch bằng Power Query.
*   [ ] Tạo Pivot Tables.
*   [ ] Xây dựng Interactive Dashboard với Slicers.

### Dự án 2: Exploratory Data Analysis - EDA (Trung cấp)
*   [ ] Dùng Python (Pandas) hoặc SQL.
*   [ ] Phân tích xu hướng (Trend analysis).
*   [ ] Tìm mối tương quan (Correlation).
*   [ ] Trả lời 5 câu hỏi kinh doanh cụ thể.

### Dự án 3: End-to-End BI Project (Nâng cao)
*   [ ] Lấy dữ liệu từ SQL Server.
*   [ ] Kết nối vào PowerBI/Tableau.
*   [ ] Xây dựng Data Model (Star Schema).
*   [ ] Tạo Dashboard chuyên nghiệp kể lại một câu chuyện (Storytelling).
