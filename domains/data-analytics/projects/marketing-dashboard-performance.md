# Case Study: Marketing Dashboard Performance

> [← Data Analytics](../README.md)

## Bối cảnh
Growth lead: “Ads spend tăng 30% nhưng signups chỉ +5%. Funnel đang nghẽn chỗ nào?”

## Metrics bắt buộc
| Metric | Định nghĩa |
| --- | --- |
| CPC / CPA | Cost per click / per signup |
| CTR | Clicks / impressions |
| CVR landing→signup | Signups / sessions landing |
| CAC | Spend / new paying (nếu có) |
| Channel mix | Spend & signups by channel |

## Deliverables
1. Dashboard (Looker Studio / Power BI / Metabase) 1 page
2. SQL: funnel weekly by channel
3. One-pager: 3 insights + 2 tests (budget shift / landing copy)

## Acceptance
- [ ] Mọi KPI có định nghĩa viết ra
- [ ] Có filter date + channel
- [ ] Chỉ ra bước funnel drop lớn nhất bằng số
- [ ] Đề xuất experiment có success metric + thời gian chạy
