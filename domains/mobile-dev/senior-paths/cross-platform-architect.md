# Cross-Platform Architect

## Trọng tâm
- Module hóa/super-app: chia feature modules, tách state theo domain.
- Platform Channels / Native Modules khi framework không đủ.
- Kiến trúc: Clean, DI, multi-package (Flutter), monorepo toolchain.

## Kỹ thuật
- Build config per-flavor, toggle feature flags.
- Performance profiling: jank, startup, memory; theo dõi crash/ANR.
- Release at scale: CI/CD, canary, remote config.
