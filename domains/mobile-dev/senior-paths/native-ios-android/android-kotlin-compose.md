# Android Kotlin/Compose Roadmap

## Trọng tâm
- Kotlin language, coroutines/Flow; Jetpack Compose UI.
- Android Studio tooling, Gradle build.
- Play Store submission, signing, Play Console.

## Bước gợi ý
- Build app Compose: navigation, state (ViewModel + Flow/StateFlow).
- Network layer (Retrofit/OkHttp), Room DB, caching.
- WorkManager cho background; notifications.
- Performance: ANR/Crash, tracing, memory (LeakCanary), startup.
