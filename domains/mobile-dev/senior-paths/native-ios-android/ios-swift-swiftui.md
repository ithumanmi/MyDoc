# iOS Swift/SwiftUI Roadmap

## Trọng tâm
- Swift language, SwiftUI UI framework; Xcode tooling.
- Concurrency (async/await), Combine cơ bản.
- Store submission, provisioning, TestFlight.

## Bước gợi ý
- Build app SwiftUI đơn giản; navigation, state.
- Network layer (URLSession, Codable), caching.
- Background tasks (BGTaskScheduler), notifications.
- Performance & profiling: Instruments (Time Profiler, Memory).
