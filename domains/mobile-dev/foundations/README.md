# Foundations (Level 1)

Ngôn ngữ, UI system, layout và vòng đời app.

## Nội dung chính
- Chọn stack: Flutter (Dart) hoặc React Native (JS/TS).
- UI basics: Widgets/Components, Stateless vs Stateful, JSX.
- Layout: Flexbox, Column/Row/Stack, List cơ bản.
- App lifecycle: init → build/render → dispose; tránh memory leak.

## Deliverables gợi ý
- Calculator app (logic + layout).
- Portfolio app (CV) với nhiều screen, navigation đơn giản.
