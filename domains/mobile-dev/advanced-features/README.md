# Advanced Features (Level 3)

## Nội dung chính
- Native features: Camera, GPS, Bluetooth, Biometric, Push/Firebase.
- Offline-first & sync: queue, conflict resolution, idempotency.
- Deep linking: Universal Links, App Links, deferred deep links.
- Background tasks: fetch, location; battery impact.

## Deliverables gợi ý
- Chat app realtime (Firestore/Socket) + push notif.
- E-commerce mini app với deep link vào product detail.
