# Responsive & Adaptive

## Nguyên tắc
- Breakpoints cho phone/tablet/desktop; cân nhắc foldables.
- Safe area, notch; tránh nội dung bị che.
- Layout adaptive: bottom sheets vs side navigation trên tablet.

## Flutter
- `LayoutBuilder`, `MediaQuery`, `Flex`; responsive grid.
- Adaptive widgets (Cupertino/Material) khi cần native feel.

## React Native
- `useWindowDimensions`, `react-native-safe-area-context`.
- Style theo breakpoint; flex, percentages.
