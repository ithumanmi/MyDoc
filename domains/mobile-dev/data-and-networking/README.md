# Data & Networking (Level 2)

API, state management, local storage, kiến trúc.

## Nội dung chính
- HTTP & JSON: REST, error/loading states, retry/backoff.
- State management: Provider/BLoC/Riverpod (Flutter); Redux/Zustand (RN).
- Local storage: SharedPreferences, SQLite/Room, Hive, Realm.
- Kiến trúc: MVVM/Clean; tách Data/Domain/Presentation.

## Deliverables gợi ý
- Weather App (API + cache offline nhẹ).
- Note App offline-first (sync khi online).
