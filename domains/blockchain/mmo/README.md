# 🎯 MMO & Retroactive Playbook

> **Goal:** Tối ưu hóa cơ hội nhận airdrop/MMO reward từ các chain mới.
> **Deliverables:** Chiến lược farming, toolset theo chain, checklist quản trị rủi ro.
> **Success Criteria:** Đạt qualifying tier, đa dạng chain, tránh bị Sybil/slash.

## 1. Khái niệm

- **MMO (Massive Mission Onchain):** Event gồm nhiều nhiệm vụ on-chain (ví dụ Galxe, LayerZero, Base Quest).
- **Retroactive Airdrop:** Team phân phối token dựa trên hoạt động trước snapshot (Optimism, Arbitrum, Starknet).
- **Point System:** EigenLayer Points, Blast Gold, Manta Points.

## 2. Strategy Framework

1. **Research:** Theo dõi dự án chưa phát token (LayerZero, zkSync, Scroll, EigenLayer AVS).
2. **Prioritize Chains:** L2/zkRollup (Base, Mantle, Blast), Appchain (Celestia rollup, Berachain testnet), Move chains (Aptos, Sui).
3. **Interaction Mix:** Bridge, swap volume, provide liquidity, mint NFT, deploy contract.
4. **Sybil Defense:** Chia ví bằng profile khác nhau, tránh pattern copy.

## 3. Tooling

- **Wallet Management:** Rabby, Frame, Safe multi-account.
- **Tracker:** Dune dashboards, airdrop hunter (Airdrops.io, Dropstab), Nansen quest.
- **Automation:** DeBridge, Bungee, LayerZero OFT bridging scripts, zkSync CLI.
- **Proof of Humanity:** Galxe Passport, Gitcoin Passport, Civic.

## 4. Featured Campaigns

| Project | Actions | Notes |
| --- | --- | --- |
| LayerZero | Use OFT, Stargate bridge, Aptos/Sui bridge | Sybil filter nặng, cần Proof of Humanity |
| zkSync Era | Bridge > $1k, swap, provide liquidity, interact with native dApp | Snapshot chưa công bố |
| Scroll | Deploy contract, use Scroll Bridge, interact with native dApps | Dev-focused, EVM equivalence |
| Base | Onchain quests (Galxe), mint NFT, use Base-native apps | Có Onchain Summer NFT series |
| Celestia Rollups (Eclipse, Dymension) | Run light node, stake, bridge data | Data availability points |

## 5. Risk Management

- **Capital Allocation:** Limit per wallet; dùng stablecoin, diversified.
- **Security:** Hardware wallet, revoke approvals định kỳ, dùng Safe ký giao dịch lớn.
- **Fee Optimization:** Chọn chain phí thấp (Linea, Base) cho volume farming.
- **Sybil Policy:** Duy trì lịch sử on-chain đa dạng (NFT, social), tránh spam nhiều ví giống hệt.

## 6. Checklist

- [ ] Lập danh sách dự án chưa phát token, theo dõi Telegram/Twitter dev update.
- [ ] Phân bổ vốn theo cluster (L2, zk, appchain, Move).
- [ ] Hoàn thành nhiệm vụ (bridge, swap, LP, NFT mint, contract deploy).
- [ ] Thu thập credential chống Sybil (Galxe Passport, Gitcoin Passport).
- [ ] Theo dõi snapshot rumor, chuẩn bị withdraw tránh khóa vốn dài hạn.
- [ ] Ghi log giao dịch (Google Sheet/Notion) để đối chiếu khi claim.
