# 🔵 Base Architecture

## 1. OP Stack Rollup

- Built on Optimism Bedrock (OP Stack) → modular components (sequencer, fault proofs, L1 contracts).
- Data posted to Ethereum mainnet, fraud proof window (7 days) until Stage 2 decentralization.

## 2. Coinbase Alignment

- Deep integrations: Coinbase wallets, exchange bridging, KYC onramps.
- Sequencer currently Coinbase-managed; roadmap toward decentralization via Superchain governance.

## 3. Superchain Vision

- Base as part of Optimism Collective Superchain, shared governance + revenue sharing (OP Stack).
- Projects can deploy OP Stack chains and interoperate via standardized bridges.

- [ ] Track Stage 1 → Stage 2 upgrades (proof system live, permissionless outputs).
