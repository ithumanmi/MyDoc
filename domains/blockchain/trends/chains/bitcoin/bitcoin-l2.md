# ⚡ Bitcoin L2 & Scaling

## 1. Lightning Network

- Payment channels, HTLC routing, onion encryption.
- Key tooling: LND, Core Lightning, Phoenix wallet.

## 2. RGB & Client-side Validation

- Smart contracts anchored vào Bitcoin via commitments.
- Off-chain state, on-chain enforcement qua Taproot.

## 3. BitVM & Rollups

- Off-chain computation + fraud proofs (semi-interactive).
- Enables Ethereum-style logic mà không fork Bitcoin.

## 4. Emerging L2s

- Botanix Spiderchain, Bison Network, Rollkit using Bitcoin DA.
- Ark protocol (payment pools), Fedimint (community custody).
