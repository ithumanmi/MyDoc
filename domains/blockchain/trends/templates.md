# 📐 Trend Module Templates

## Lab Template

```
## 🧪 Lab: <Lab Title>

**Goal:** <One-line objective>

**Prerequisites:**
- Tooling: <CLI/SDK>
- Network: <Testnet/Mainnet>
- Skills: <Solidity, Node.js, etc>

### Steps
1. ...
2. ...
3. ...
4. ...

**Metrics to Track:** latency, success rate, costs, rewards.

**Deliverables:** <Artifacts + evidence>
```

## Case Study Template

```
## 🧾 Case Study: <Project>

- **Context:** <Timeframe + scenario>
- **Key Metrics:** TVL, users, revenue, emissions.
- **Architecture Snapshot:** diagram/reference.
- **Key Insights:** bullet list of 3-4 lessons.
- **Risks & Mitigations:** ...
- **Takeaway:** <single sentence>
```

## Usage

- Cập nhật mọi module trend theo format này để người đọc nắm nhanh.
- Tái sử dụng checklist metrics giúp so sánh giữa các trend.
