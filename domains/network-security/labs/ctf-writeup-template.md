# 📝 CTF Writeup Template

> Template chuẩn để ghi lại quá trình solve challenge/box, dễ chia sẻ và học lại.

---

## 1. Metadata
- Challenge/Box name:
- Platform (HTB, VulnHub, CTFtime event):
- Category (Web, Crypto, Pwn, DFIR...):
- Difficulty:
- Date solved:
- Team/solo:

---

## 2. TL;DR
- Summary exploit chain.
- Flag format.
- Key takeaway (1 câu).

---

## 3. Environment
- Tool version (Burp 2024.x, Python 3.11).
- VM/Container setup.
- Special config (proxy, custom scripts).

---

## 4. Recon / Enumeration
- Command list (`nmap`, `dirsearch`, `linpeas`).
- Result screenshot/link.
- Observations (service version, path interesting).

---

## 5. Exploitation
- Step-by-step exploit.
- Payload snippet/code block.
- Troubleshooting.

---

## 6. Privilege Escalation / Post-exploitation
- Enumeration result (linPEAS, winPEAS).
- Exploit chain tới root/system.
- Persistence/loot.

---

## 7. Detection & Defense Notes
- Indicator of Compromise (IOCs).
- Sigma/YARA idea.
- Hardening recommendation.

---

## 8. Lessons Learned
- Sai lầm gặp phải.
- Tool/script cần cải thiện.
- Thời gian solve vs target.

---

## 9. References
- Official hint, blog.
- CVE or exploit link.

---

## Checklist
- [ ] Có screenshot minh họa.
- [ ] Source code/payload được lưu repo.
- [ ] Detection idea ghi rõ MITRE.
- [ ] Share lại cho team/community.
