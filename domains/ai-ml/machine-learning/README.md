# 🧠 Classic Machine Learning Hub

> [← Back to AI/ML Roadmap](../README.md)

Tổng hợp tài nguyên Classic ML theo flow thực chiến: hiểu bài toán → xây pipeline → tối ưu → deploy. Dùng hub này để điều hướng nhanh giữa Supervised, Unsupervised, Ensemble và các module hỗ trợ.

---

## 📌 Learning Path

1. **Supervised Learning** → Regression/Classification playbook.
2. **Unsupervised Learning** → Clustering, giảm chiều, anomaly.
3. **Semi-supervised & Feature Engineering** → Nâng chất dữ liệu.
4. **Ensemble Methods & Model Selection** → Tối ưu hiệu năng.
5. **Practice + Deployment** → Bài tập, lab, template triển khai.

> 🎯 Tip: Bắt đầu với `supervised-learning.md` để xác định baseline → chuyển sang `unsupervised-learning.md` khi cần khám phá dữ liệu → dùng `ensemble-methods.md` nếu cần push thêm accuracy.
