# Fullstack (Level 3)

Next.js/Node, TypeScript, database, auth.

## Nội dung chính
- Meta-framework: Next.js (SSR/SSG, server actions/API routes).
- TypeScript: types, generics, strict mode.
- Database: Postgres/Mongo + Prisma ORM.
- Auth: JWT/OAuth, session vs token, NextAuth/Clerk (overview).

## Deliverables gợi ý
- Blog platform (CMS + SEO + markdown render).
- Trello clone (drag-drop, realtime optional, auth).
