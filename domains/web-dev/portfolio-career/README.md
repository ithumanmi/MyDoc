# Portfolio & Career

Tóm tắt checklist portfolio, phỏng vấn, liên kết guides.

## Portfolio checklist
- Live demo (Vercel/Netlify/Render), repo có README đẹp.
- Performance: Lighthouse > 90.
- Case study blog: thách thức và cách giải quyết.

## Interview prep (tóm tắt)
- React: Virtual DOM, memoization, prop drilling.
- JS: closure, event loop, hoisting.
- System design (senior): URL shortener, news feed.
