# 📧 Gmail Creation SOP

## 1. Environment
- Residential/4G proxy, OS timezone khớp region.
- Chrome profile sạch, không đăng nhập account khác.
- Phone/SIM ready cho OTP.

## 2. Steps
1. Truy cập `https://accounts.google.com/signup`.
2. Điền họ tên hợp lý, username không spammy.
3. Password mạnh + recovery email.
4. Verify phone (SIM trùng region) → nhập OTP.
5. Bật 2FA (Google Prompt hoặc Authenticator).

## 3. Hygiene
- Thêm info: birthday, gender.
- Enable backup codes, lưu vào vault.
- Login via IMAP/SMTP một lần để kích hoạt.

## 4. Automation Tips
- Selenium/Playwright: random typing delay, viewport mobile/desktop.
- Đừng reuse phone number quá 5 lần/ngày.

## 5. Checklist
- [ ] OTP verified.
- [ ] Recovery email/phone set.
- [ ] Backup codes lưu trữ.
