# 🔥 Facebook Warming Schedule (Day 1-30)

## Principles
- Human-like activity, tăng dần trust signals.
- Không chỉnh sửa info quá nhiều trong 7 ngày đầu.
- Track mọi action (sheet) để audit.

## Timeline
| Day | Action |
| --- | --- |
| 1-3 | Login 2 lần/ngày, lướt newsfeed 30 phút. Add 3 bạn bè quen, comment nhẹ. |
| 4-7 | Join group niche, tương tác post (like/share). Boost post $5/day nếu có page. |
| 8-14 | Tạo page, chạy Page Like campaign nhỏ. Checkpoint rate mục tiêu <2%. |
| 15-21 | Conversion campaign nhỏ (pixel warm). Spend tăng 10-15%/day. |
| 22-30 | Push ngân sách $300-$500/day. Maintain payment success, response support nếu có review. |

## Guardrails
- IP + device không đổi trong 30 ngày.
- Payment thử transaction nhỏ trước khi scale.
- Nếu bị limit, pause 48h, gửi appeal.

## Checklist
- [ ] Log daily activity.
- [ ] Payment method verified.
- [ ] Pixel/Events setup trước day 15.
