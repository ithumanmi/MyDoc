# 🛡️ Facebook Checkpoint Recovery

## 1. Common Checkpoints
- Photo verify (nhận dạng bạn bè).
- ID upload (CMND/passport).
- Confirm recent activity/device.

## 2. Preparation
- Lưu lịch sử login (IP, device).
- Có bộ ảnh chuẩn (avatar, friend list) để manual review.
- Chuẩn bị ID template (PSD), info khớp profile.

## 3. Recovery Flow
1. Login → thấy checkpoint.
2. Dùng cùng proxy/device như trước.
3. Nếu photo verify: chuẩn bị danh sách bạn bè thật, note URL.
4. Nếu ID: upload file JPEG <2MB, scan rõ, metadata khớp.
5. Theo dõi email support, reply trong 24h.

## 4. Automation Guardrails
- Tool auto-alert khi response FB yêu cầu thêm thông tin.
- Đừng brute force checkpoint (tối đa 3 lần/ngày).

## 5. Checklist
- [ ] Profile log đầy đủ.
- [ ] Asset (photo, ID) cập nhật theo info mới nhất.
- [ ] Có backup account để tiếp tục campaign trong thời gian chờ.
