# 🖥️ UI/UX for Games

> Mục tiêu: giao diện rõ ràng, phản hồi tức thời, truy cập (accessibility) tốt, và tối ưu cho cả pad/KBM/mobile.

## Checklist nhanh
- [ ] Đảm bảo HUD ưu tiên thông tin cốt lõi, có hierarchy, và tùy biến scale.
- [ ] Menu flow rõ ràng: back/cancel nhất quán, trạng thái focus/hover, không mất input.
- [ ] Accessibility: color-blind safe, subtitle/captions, remap input, text size/contrast.
- [ ] Feedback/juice: hit stop, screen shake kiểm soát cường độ, âm thanh/FX rõ ràng.
- [ ] Mobile touch: thumb zones, gesture pattern rõ, mục tiêu chạm đủ lớn.
