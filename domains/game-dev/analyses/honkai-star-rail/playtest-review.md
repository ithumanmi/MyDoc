## 1. Success criteria

Players can explain Toughness Break and SP tradeoff unprompted after FTUE; enable Auto only after one manual elite. `(proposed)`

## 2. Protocol (~75 min inspired slice)

| Task | Timebox | Observe |
| --- | --- | --- |
| FTUE combat through first Break elite | 20m | Icon literacy |
| SP-starved fight (forced) | 15m | Basic vs Skill talk-aloud |
| One “daily Power” farm loop | 15m | Auto trust / boredom |
| Mini timer clear (MoC-lite) | 15m | Comp swapping intent |
| Debrief | 10m | Pillars recall |
