## 6. Lessons

1. If GaaS + TB → **Auto/Manual split** must be intentional in design docs.  
2. If collection meta → **cycle endgame** before infinite vertical only.  
3. If gacha → pity + occasional selectors; still design **skip culture**.  
4. Port patterns ≠ port Hoyoverse cost structure.
