# Analysis pack — quality bar

> [← Analyses](./README.md) · Teardown template: [game-systems-teardown.md](../game-design/templates/game-systems-teardown.md)  
> Mục tiêu: systems writing kiểu **Infect Them All** (mechanism + tradeoff), không store-page.

## When is a teardown “dense enough”?

| Must have | Fail if… |
| --- | --- |
| One **thesis** that names a **role inversion** vs comps | “Game hay / graphics đẹp” |
| Core action **chain** + ± feedback | Feature list không physics |
| **Phases** với agency change | Một cột “gameplay” suốt campaign |
| Core / Meta / Live tách bảng | Shop UI nhét vào core loop |
| 2–3 **decision axes** (+/− / khi nào) | Chỉ liệt kê mode |
| Escalation tiers + **anti–power-creep lever** | “Càng mạnh càng dễ” không brake |
| Economy friction (hoặc link sheet) không bịa KPI | Fake D1/D7 / ARPU |
| UX/psychology dưới density | Chỉ lore |
| Transfer + open verify | Copy section Infection lên mọi genre |

Evidence tags: `(observed)` · `(inferred)` · `(genre pattern)` · `(assumed)` / `(TBD)`.

## Genre adapters (don’t force one metaphor)

| Family | Probe extras |
| --- | --- |
| GaaS / live | Cycle FOMO, catch-up, Auto vs Manual |
| Premium narrative / SRPG | Branch ownership, NG+ breadth |
| Infection / arcade growth | Unit tipping, density UX |
| Roguelike | Run vs meta, death tax |
| Puzzle | First-48h fails, hint economy |

## Anti-patterns

- Mega-file dump thay vì folder pack  
- Teardown = wiki copy  
- Playtest scores bịa / postmortem “team said” không nguồn  
- Leisure taste notes trong Make pack → dùng `guides/05-games-os/play/`
