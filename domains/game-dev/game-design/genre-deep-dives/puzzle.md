# 🧩 Puzzle Game Deep Dive

## Pillars
- Clear mechanic comprehension + depth.
- Level design pacing (easy → mastery).
- Content cadence liên tục.

## Core Loop
1. Chọn level.
2. Solve (match, logic, physics).
3. Nhận reward (stars, currency) → spend vào meta (decor, room).

## Meta Integration
- Renovation/decoration meta.
- Narrative chapter unlock.
- Collection/crafting (boosters).

## KPI
- Session length: 8-12 phút.
- Level completion rate target 70-80% early, 50% mid.
- D1 retention 35-45%, D7 12-18%.
- Monetization: booster packs, extra moves, season pass.

## Content Production
- Level factory pipeline (template, difficulty tagging).
- A/B test new mechanic via event island.
- Tooling: level editor export csv/json.

## Risks
- Difficulty spike → drop-off.
- Booster dependency.
- Content drought.

## ✅ Apply it
- [ ] Thiết lập level taxonomy + difficulty curve.
- [ ] Gắn meta (decor/story/collection) để giữ retention.
- [ ] Lên roadmap content (X level/week).
- [ ] Track level telemetry (fail type, booster use).
