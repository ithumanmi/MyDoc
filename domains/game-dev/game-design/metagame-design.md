# ♟️ Metagame Design

## 1) Progression Pillars
- **Horizontal**: mở khóa hero, card, skill tree branch.
- **Vertical**: nâng cấp power level, gear score, rarity.
- **Prestige/Reset**: loop reset (Ascension, Season reset) để recycle content.
- KPI: D7/D30 retention, sink-source economy, session length.

## 2) Collection Systems
- Album/completion (Pokedex, sticker book). Use rarity tiers + showcase UI.
- Drop table design: pity system, duplicate protection, crafting.
- Collection power: buff passive (set bonus) → gắn kinh tế.
- Social leverage: share collection, spectate loadout.

## 3) Missions & Live Goals
- Daily/Weekly missions: mix short vs long-term, align event calendar.
- Battle Pass: free/paid track, challenge bucket (skill, grind, social).
- Seasonal meta: questline, limited currency → sink for cosmetics.

## 4) Social Features
- Guild/clan system: contributions, perks, asynchronous co-op.
- Friend leaderboard, spectate, gifting.
- UGC meta: level editor, share codes, rating → organic retention.
- Ensure moderation + report pipeline.

## 5) Meta Loop Architecture
1. Core loop (play match) → Earn resource → Spend trong meta (upgrade/collection) → Unlock content.
2. Use diagrams (State Machine / Economy chart) để show flow.
3. Define content cadence (new card weekly, new map monthly).

## 6) Analytics
- Track meta engagement: % player active in missions, BP completion, collection completeness.
- Cohort: whales vs dolphins vs minnows – adjust meta sinks.
- Use segmentation to unlock features (guild at level 10 → ensure skill).

## ✅ Apply it
- [ ] Xác định meta pillar (progression, collection, social) phù hợp genre.
- [ ] Thiết kế economy sink-source hỗ trợ meta.
- [ ] Lên calendar mission/event → integrate battle pass.
- [ ] Triển khai social layer + moderation.
- [ ] Đặt KPI meta (BP completion, collection rate) và dashboard.
