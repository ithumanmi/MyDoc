# 🎯 Những kiến thức cần nắm để trở thành Game Designer

> Game designer không chỉ “nghĩ idea”. Họ là người dịch mục tiêu kinh doanh → trải nghiệm chơi → hệ thống đo lường. Tài liệu này tổng hợp năng lực cần xây dựng nếu bạn muốn bước vào nghề (hoặc phát triển xa hơn).

## 1. Mindset & Nền tảng tư duy
- **Player-first:** Hiểu động lực, tâm lý, hành vi. Dùng dữ liệu + định tính.
- **System thinking:** Mọi tính năng là một hệ thống với input/output.
- **Iteration & feedback:** Build → test → learn → chỉnh liên tục.
- **Cross-discipline empathy:** Biết ngôn ngữ art, code, marketing để phối hợp.

## 2. Kiến thức cốt lõi theo trục kỹ năng
### 2.1 Game Theory & Core Loop
- Nắm concept loop: engagement, economy, progression.
- Biết cách xác định KPI cho từng giai đoạn (đọc thêm: [Core Loop Mastery](./core-loop-mastery.md)).

### 2.2 Systems & Economy Design
- Soft/Hard currency, sinks/sources, live ops economy.
- Công cụ balancing, simulation.
- Tham khảo: [economy-systems.md](./economy-systems.md).

### 2.3 Level & Content Design
- Flow, pacing, difficulty curve, gating.
- Tooling (Unity tools, custom editors) để build nhanh.

### 2.4 Narrative & Meta Experience
- Story structure, quest, character arcs.
- Meta progression: collections, streaks, battle pass.
- Tham khảo: [narrative-toolkit.md](./narrative-toolkit.md).

### 2.5 UX, Telemetry & Playtest
- Wireflow, UI feedback, accessibility.
- Telemetry pipeline, event design, survey.
- Tham khảo: [playtest-framework.md](./playtest-framework.md), [Unity Impact Metrics](../metrics/unity-impact-metrics.md).

### 2.6 Production & Collaboration
- Sprint planning, feature spec, backlog prioritization.
- Hand-off rõ ràng cho engineer, artist, QA.

## 3. Kỹ năng bổ trợ hiện đại
- **Data literacy:** Hiểu cohort, retention, funnel. Biết dùng SQL/basic BI.
- **Monetization & Live Ops:** Battle pass, events, pricing.
- **Tooling:** Engine (Unity/Unreal), version control (Git), prototyping tool (Figma, Miro).
- **Communication:** Viết GDD ngắn gọn, storyboard, pitching.

## 4. Lộ trình học gợi ý
1. **Foundation (0-3 tháng):** Học core loop, UX cơ bản, làm mini game jam.
2. **Specialization (3-9 tháng):** Chọn mảng (level, systems, narrative) và xây portfolio.
3. **Production-ready (9-18 tháng):** Join team indie/studio, học process cross-functional.
4. **Scaling (18+ tháng):** Học live ops, data-driven design, leadership.

## 5. Tài nguyên nên đọc/làm
- Sách: *The Art of Game Design*, *Game Balance Concepts*.
- Newsletter/Podcast: Deconstructor of Fun, GameDev.tv.
- Thực hành: tham gia jam, thiết kế lại mechanic game quen thuộc.
- Tài liệu trong repo: [Game Review Checklist](./game-review-checklist.md), [Puzzle Hidden Systems](./puzzle-hidden-systems.md).

## 6. Checklist tự đánh giá
- [ ] Hiểu rõ player archetype & nhu cầu tâm lý.
- [ ] Có thể mô hình hóa core loop bằng sơ đồ + KPI.
- [ ] Biết thiết kế economy cân bằng (currency, sinks, faucets).
- [ ] Thành thạo ít nhất một công cụ prototyping/engine.
- [ ] Viết được spec/ngắn gọn cho dev/art.
- [ ] Biết đọc số liệu retention, session, monetization.
- [ ] Có portfolio prototype hoặc live feature.

## 7. Next Steps
- Chọn 1 mảng yếu nhất và đặt mục tiêu học trong 4 tuần.
- Xây “learning project” nhỏ (ví dụ: thiết kế 5 level có difficulty curve rõ ràng).
- Tìm mentor hoặc community để nhận feedback liên tục.

## 8. Lộ trình cho các sub-specialty
### Level Designer
- **0-3 tháng:** Làm lại level của game quen, học pacing/difficulty curve.
- **3-9 tháng:** Build 20-30 level original, test với người chơi thật.
- **9-18 tháng:** Làm việc với toolchain (tilemap editor, scripting). Tập trung polish onboarding.
- **18+ tháng:** Chịu trách nhiệm cả world map, integrate narrative meta, mentoring junior.

### Systems / Economy Designer
- **0-3 tháng:** Học khái niệm currency, sinks/sources, core loop metrics.
- **3-9 tháng:** Dùng spreadsheet/ simulator để cân bằng economy nhỏ.
- **9-18 tháng:** Thiết kế live ops event, pricing packs, A/B test.
- **18+ tháng:** Lead balancing roadmap, thiết lập KPI mục tiêu cho product.

### Narrative / Meta Designer
- **0-3 tháng:** Viết short quest, character bible, học branching cơ bản.
- **3-9 tháng:** Ghép narrative vào core loop (ví dụ: meta progression song song gameplay).
- **9-18 tháng:** Hợp tác chặt với art/audio để đồng bộ mood; quản lý localization pipeline.
- **18+ tháng:** Thiết kế meta systems (streak, collections) gắn với live ops.

### UX / Telemetry Designer
- **0-3 tháng:** Học wireframe cơ bản, UX patterns cho mobile/PC.
- **3-9 tháng:** Xây prototype UI, chạy usability test nhỏ.
- **9-18 tháng:** Thiết kế event telemetry, dashboard KPI, kết hợp product analyst.
- **18+ tháng:** Dẫn dắt data-informed UX, tối ưu funnel onboarding → paywall.

### Live Ops & Monetization Designer
- **0-3 tháng:** Nắm thương mại hóa cơ bản: ad placement, IAP, event cadence.
- **3-9 tháng:** Thiết kế mini live event, reward track.
- **9-18 tháng:** Lên lịch season pass, sync với UA/CRM team.
- **18+ tháng:** Chịu trách nhiệm P&L live ops, phối hợp marketing & data science.

### Technical / Tools Designer
- **0-3 tháng:** Học scripting nhẹ (Lua/C#), hiểu engine pipeline.
- **3-9 tháng:** Xây tool nhỏ hỗ trợ level/content team.
- **9-18 tháng:** Chuẩn hóa workflow: template, automation, perf metrics.
- **18+ tháng:** Thiết kế tool cho live editing, hỗ trợ rapid experimentation.
