# 🗺️ Level Design

> Mục tiêu: tạo trải nghiệm dẫn dắt người chơi mạch lạc, nhịp độ hợp lý, có cột mốc định hướng, kể chuyện môi trường, và pipeline blockout → art hiệu quả.

## Checklist nhanh
- [ ] Xác định fantasy/goal và đường dẫn chính-phụ; thiết lập landmarks/visual language.
- [ ] Thiết kế nhịp pacing (combat/rest/puzzle) và cường độ theo đoạn.
- [ ] Định hình difficulty curve (onboarding → ramp → mastery → finale) kèm tutorial in-context.
- [ ] Quyết định thủ công vs thủ tục (procgen) và khối lượng authoring tương ứng.
- [ ] Blockout greybox, review flow/metrics, rồi art pass + lighting/readability.
