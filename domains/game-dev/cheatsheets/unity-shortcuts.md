# ⚡ Unity Editor Shortcuts

| Action | Shortcut |
| --- | --- |
| Move Tool | `W` |
| Rotate Tool | `E` |
| Scale Tool | `R` |
| Rect Tool (UI) | `T` |
| Vertex Snapping | Hold `V` + drag |
| Duplicate | `Ctrl + D` |
| Focus object | `F` |
| Frame All | `Shift + F` |
| Play/Pause | `Ctrl + P` / `Ctrl + Shift + P` |
| Step | `Ctrl + Alt + P` |
| Toggle Game/Scene View | `Ctrl + Tab` |
| Toggle Inspector Lock | Click lock icon or `Ctrl + L` |
| Search Command | `Ctrl + K` (Quick Search) |
| Prefab Mode | `Ctrl + Shift + P` (Edit Prefab) |
| Multi-object Rename | `Ctrl + F2` |
| Align View to Selected | `Ctrl + Shift + F` |

## Tips
- Setup custom shortcut via **Edit > Shortcuts**.
- Use **Quick Search** package để tìm asset/script.
- Combine gizmo hotkeys với `Ctrl` để snap rotation (15°).
