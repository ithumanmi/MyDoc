# 📋 Kịch bản quản lý 3 dự án cùng lúc

> [← Templates Index](./TEMPLATES-INDEX.md) | [Personal Work Framework](../guides/03-career-skills/productivity/core-skills/personal-work-framework.md) | [Time Management](../guides/03-career-skills/productivity/core-skills/time-management-systems.md)
>
> **Mục đích:** Một tuần làm việc mẫu khi bạn đang chạy **3 dự án song song** — vừa không bỏ sót, vừa giữ được deep work cho từng dự án.

---

## 1. Nguyên tắc vàng (3 dự án)

| Nguyên tắc | Giải thích ngắn |
|:-----------|:-----------------|
| **Mỗi ngày tối đa 2 dự án** | Tránh nhảy cóc 3–4 dự án trong 1 ngày; mỗi ngày ưu tiên 1 dự án "chính" + 1 dự án "phụ" (hoặc admin). |
| **Day Theming** | Gán mỗi dự án vào 1–2 ngày cố định trong tuần để não vào "context" nhanh. |
| **Block tối thiểu 2h cho deep work mỗi dự án** | Mỗi lần chạm vào dự án ít nhất 2 giờ tập trung, tránh 30 phút rải rác. |
| **Một buổi "đa nhiệm" cố định** | Dồn email, update, họp nhanh của cả 3 dự án vào 1 khung (ví dụ sáng T2 hoặc chiều T6). |
| **Review 3 dự án mỗi cuối tuần** | 30 phút: tiến độ từng dự án, rủi ro trễ hạn, tuần sau ưu tiên gì. |

---

## 2. Cấu trúc tuần mẫu (áp dụng cho 3 dự án)

Giả sử 3 dự án: **A** (Client/Work), **B** (Học/Cá nhân), **C** (Side/Internal).

| Ngày | Dự án chính (Deep 2–4h) | Dự án phụ / Admin |
|:-----|:------------------------|:------------------|
| **Thứ 2** | Sync & Plan (xem cả 3 dự án, cập nhật task) | Họp/email dự án A, B, C gom 1 buổi |
| **Thứ 3** | **A** | Việc nhỏ B hoặc C (< 1h) |
| **Thứ 4** | **B** | Việc nhỏ A hoặc C (< 1h) |
| **Thứ 5** | **A** (hoặc C nếu A đã ổn) | Shallow: email, báo cáo |
| **Thứ 6** | **C** | Review tuần, plan tuần sau, admin |

*Lưu ý:* Nếu một dự án có deadline gấp, có thể dồn 2 ngày liên tiếp cho dự án đó; tuần sau bù lại 2 ngày cho 2 dự án kia.

---

## 3. Ví dụ cụ thể: 3 dự án trong 1 tuần

### Giả định
*   **Dự án A — Website cho Client X:** Deadline bàn giao 2 tuần nữa. Tuần này: hoàn thành 3/5 màn hình + review với client.
*   **Dự án B — Ôn thi chứng chỉ (CFA/IELTS/…):** Mục tiêu 5 buổi × 2h. Tuần này: 2 môn (M1, M2), mỗi môn 2 buổi.
*   **Dự án C — Nội dung cho kênh (YouTube/Newsletter):** 1 video hoặc 1 bài/tuần. Tuần này: script + quay hoặc viết draft.

### Phân bổ theo ngày (ví dụ)

| Ngày | Khung giờ (gợi ý) | Nội dung |
|:-----|:------------------|:---------|
| **T2** | 8h30–9h30 | **Sync:** Xem backlog A, B, C; cập nhật lịch; ghi 3 ưu tiên lớn tuần. |
| | 9h30–10h30 | Email + tin nhắn liên quan A, B, C (batch). |
| | 10h30–12h30 | **Deep A:** Code/design 2 màn hình Website. |
| | 14h–16h | **Deep A:** Màn hình thứ 3 + gửi link review cho Client X. |
| **T3** | 8h30–10h30 | **Deep A:** Sửa theo feedback (nếu có) hoặc tiếp 2 màn còn lại. |
| | 11h–12h | **B:** Học M1 (1 chương + 10 câu bài tập). |
| | 14h–16h | **Deep A:** Hoàn nốt phần giao client tuần này. |
| **T4** | 8h30–10h30 | **Deep B:** Học M2 (1 chương + bài tập). |
| | 11h–12h | **C:** Viết outline script video / cấu trúc bài. |
| | 14h–16h | **Deep B:** Ôn M1 + làm thêm bài tập M2. |
| **T5** | 8h30–10h30 | **Deep C:** Viết script đầy đủ hoặc quay video. |
| | 11h–12h | **A:** Trả lời client, cập nhật task, chuẩn bị demo. |
| | 14h–16h | **Deep A hoặc C:** Tùy A còn bug/demo hay C cần edit. |
| **T6** | 8h30–10h30 | **Deep C:** Edit video / biên tập bài; đăng hoặc lên lịch đăng. |
| | 11h–12h | **Review tuần:** A — đã giao đủ? B — đủ 5 buổi chưa? C — đã ra nội dung? |
| | 14h–15h | Plan tuần sau: 3 ưu tiên A, B, C; điều chỉnh ngày theme nếu cần. |

---

## 4. Checklist hàng ngày (khi chạy 3 dự án)

**Sáng (5–10 phút):**
- [ ] Hôm nay **dự án chính** là gì? (Đúng với Day Theme.)
- [ ] **2–3 task cụ thể** phải xong của dự án chính?
- [ ] Có **deadline/ cuộc họp** nào của 2 dự án kia cần nhớ không?

**Tối (5 phút):**
- [ ] Dự án chính hôm nay đã đạt ít nhất 1 milestone chưa?
- [ ] Ngày mai vẫn giữ theme hay đổi (ví dụ có meeting gấp dự án khác)?

---

## 5. Khi có xung đột (urgent từ 1 dự án)

* **Nguyên tắc:** Ưu tiên theo **hậu quả nếu trễ** (client quan trọng, deadline cứng) chứ không theo "ai gửi email sau cùng".
* **Hành động:**  
  - Việc gấp < 30 phút: xử lý ngay trong khung "shallow" (ví dụ sau deep block).  
  - Việc gấp > 1h: đổi **tối đa 1 ngày** trong tuần sang dự án đó; ghi lại "tuần sau bù" cho dự án bị lùi.

---

## 6. Công cụ gợi ý

*   **Lịch:** 1 calendar duy nhất, mỗi block ghi rõ **[A]**, **[B]**, **[C]** + tên task.
*   **Task:** 1 app (Todoist/Notion/Tasks) với 3 project/list A, B, C; mỗi tuần mỗi dự án có 3–5 task "must do".
*   **Review tuần:** Dùng [Weekly Review](./weekly-review.md), thêm phần "Tiến độ A / B / C" và "Rủi ro trễ hạn".

---

## 7. Điều chỉnh cho bạn

*   **Chỉ có 2 ngày deep work/tuần:** Gán 1 ngày cho A, 1 ngày cho B; C làm vào cuối tuần hoặc 2–3 buổi tối ngắn.
*   **Một dự án là "main job":** A = full-time, B và C chia đều 2–3 buổi/tuần.
*   **Học + 2 client:** B = học cố định 3 buổi; A và C mỗi cái 2 ngày, hoặc A 3 ngày / C 1 ngày nếu A quan trọng hơn.

Copy bảng **§2** và **§3** vào Notion/Google Sheet, thay A/B/C bằng tên dự án thật và điều chỉnh ngày/giờ theo lịch của bạn.
