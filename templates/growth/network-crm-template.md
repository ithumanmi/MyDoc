# 🗂️ Personal Networking CRM (Notion/Airtable Template)

| Field | Gợi ý ghi chú |
| --- | --- |
| **Name** | Họ tên đầy đủ + nickname |
| **Role/Company** | Vị trí hiện tại, dự án, ngành |
| **How we met** | Sự kiện, ngày tháng, người giới thiệu |
| **Interests** | Chủ đề họ đam mê (AI, giáo dục, crypto…) |
| **Needs/KPI** | Họ đang tìm gì? (talent, funding, partnership) |
| **Value we can give** | Tài nguyên, mối quan hệ, insight phù hợp |
| **Follow-up History** | Ghi lại email/call + kết quả |
| **Next Action & Date** | Việc cần làm tiếp theo, deadline |
| **Touch Level** | High / Medium / Light (tần suất chạm) |

### Hướng dẫn sử dụng

1. Import template vào Notion hoặc Airtable.
2. Mỗi tuần cập nhật ít nhất 3 entry (người mới hoặc follow-up).
3. Lọc theo “Next Action” để ưu tiên người cần chạm.
4. Dùng view Calendar để xem lịch follow-up.

> 📌 *Tip:* Đặt reminder định kỳ (ví dụ mỗi thứ Sáu) để duyệt CRM và lên kế hoạch chạm lại.
