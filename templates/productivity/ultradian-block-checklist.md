# ✅ Ultradian Block Checklist (90/20)

## 1. Pre-Block Ritual (5 phút)
- [ ] Thở sâu 2 phút (box breathing/physiological sigh)
- [ ] Review mục tiêu 1 câu: _"Trong 90 phút tới tôi sẽ..."_
- [ ] Dọn desk + đóng thông báo + điện thoại sang phòng khác
- [ ] Chuẩn bị nước + earphones/playlist tập trung
- [ ] Chạy 2 phút mobility nhẹ (neck rolls, shoulder circles)

## 2. Deep Work Sprint (90 phút)
- [ ] Bắt đầu timer 90 phút (Focus/Forest/Notion timer)
- [ ] Single-task: chỉ 1 backlog item, cấm context switching
- [ ] Chunk nhiệm vụ thành 3 checkpoint (30p/30p/30p)
- [ ] Ghi nhanh ý tưởng phụ vào giấy, không mở app khác
- [ ] 60 phút: self-check (năng lượng, tư thế, nước)

## 3. Active Rest (15-20 phút)
- [ ] Tắt timer, đứng dậy ngay lập tức
- [ ] Ra ngoài hít thở + nhìn xa 20m
- [ ] Đi bộ nhẹ hoặc 20 squats + giãn cơ cổ vai
- [ ] Uống nước + thêm pinch muối nếu cần
- [ ] Không chạm điện thoại MXH/game (nếu cần, dùng chế độ Focus)

## 4. Debrief & Log (3 phút)
- [ ] Score block (1-5) về Focus & Energy
- [ ] Ghi lại 1 insight / block tiếp theo
- [ ] Nếu còn >=2 block: ăn nhẹ (protein/fat) trước block mới

> Gợi ý: chạy 2-3 block buổi sáng, chiều dành cho họp/shallow work.
