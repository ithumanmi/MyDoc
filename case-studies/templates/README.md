# 📚 Case Study Templates – Hướng dẫn sử dụng

Thư mục này chứa các **phiếu trả lời (answer templates)** dùng kèm với các bộ **Knowledge Audit** trong `case-studies/knowledge-audits`. Mỗi template giúp bạn:

1. Ghi lại câu trả lời cho từng “Thử thách” (challenge) theo định dạng thống nhất.
2. Tự đánh giá bằng rubric 1–10 nhờ bảng “Self-Scoring”.
3. So sánh với góc nhìn chuyên gia đã được biên soạn ở file knowledge audit tương ứng.

---

## 🧭 Cách sử dụng nhanh
1. **Chọn lĩnh vực** bạn muốn kiểm tra (ví dụ Backend, AI, Game Dev…).
2. **Mở file template** tương ứng, copy nội dung sang Google Docs/Notion hoặc viết trực tiếp.
3. Với mỗi mục “Thử thách”, điền câu trả lời kèm phân tích, ví dụ, sơ đồ hoặc pseudo-code tùy đề.
4. Sau khi hoàn thành, mở **Answer Key** tương ứng (đường link đã có trong mỗi template) để đối chiếu.
5. Ghi điểm tự chấm ở bảng “Self-Scoring” để theo dõi tiến bộ.

> Tip: Bạn có thể tải template về, đổi sang định dạng form điền tay để dùng trong workshop hoặc phỏng vấn nội bộ.

## ✅ Gợi ý mở rộng
- Thêm hướng dẫn mini ở đầu mỗi “Thử thách” (ví dụ: nên trả lời dạng bullet/diagram/code snippet?).
- Đặt checklist “Chuẩn bị trước khi audit” (đọc trước tài liệu, nhớ đo thời gian làm bài).
- Tạo version Notion / Google Docs sẵn để dễ chia sẻ trong team.

Chúc bạn stress-test năng lực thật sâu và có dữ liệu rõ ràng để upgrade kỹ năng! 🚀
