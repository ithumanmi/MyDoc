High-converting landing page copywriting templates for indie hackers launching products. Based on proven formulas from successful SaaS companies.

---

## 🎯 The Perfect Landing Page Structure

```
1. Hero Section (Above the fold)
2. Social Proof (Optional for MVP)
3. Features/Benefits (3-5 key points)
4. How It Works (3 steps)
5. Pricing (Simple is better)
6. FAQ (Address objections)
7. Final CTA
```

**Length:** Keep it concise. Readers decide in 5 seconds.

## 🎯 Copywriting Formulas

### 1. PAS (Problem-Agitate-Solution)

```
Problem: Scheduling meetings takes 10+ emails
Agitate: You waste 5 hours/week on calendar coordination
Solution: [Your Product] automates it in 1 click
```

### 2. AIDA (Attention-Interest-Desire-Action)

```
Attention: "Stop wasting time on email tennis"
Interest: "Smart scheduling tool for busy professionals"
Desire: "Join 10k+ users saving 5 hours/week"
Action: "Start Free Trial"
```

### 3. BAB (Before-After-Bridge)

```
Before: Manual calendar coordination, missed meetings
After: Automated scheduling, 100% booked
Bridge: [Your Product] makes it happen
```

## ✅ Landing Page Checklist

### Above the Fold
- [ ] Clear value proposition (5-second test)
- [ ] One primary CTA (contrasting color)
- [ ] Hero image/video showing product
- [ ] No navigation menu (Reduce distractions)

### Copy Quality
- [ ] Benefits > Features
- [ ] Specific numbers (not "many users" → "10,000 users")
- [ ] Addresses target audience pain
- [ ] Simple language (8th-grade level)
- [ ] No jargon (unless B2B technical product)

### Social Proof
- [ ] Testimonials with photos/names
- [ ] Logos of customers/partners
- [ ] Metrics (users, reviews, uptime)

### CTAs
- [ ] 3-5 CTA buttons throughout page
- [ ] Action-oriented text ("Start Free Trial" not "Submit")
- [ ] Remove friction ("No card required")

### Trust Signals
- [ ] Privacy policy link
- [ ] Security badges (SSL, SOC2 if applicable)
- [ ] Money-back guarantee
- [ ] FAQ answering objections

### Technical
- [ ] Mobile responsive
- [ ] Load time < 3 seconds
- [ ] Working CTA buttons
- [ ] Analytics installed (GA4, Plausible)

## 💡 Pro Tips

### Tip 1: The 5-Second Test

Show landing page to a friend for 5 seconds.

**Ask:** "What does this product do?"

If they can't answer → Unclear value proposition → Rewrite hero section.

---

### Tip 2: Remove, Don't Add

**Bad landing pages:** Overwhelming with info

**Good landing pages:** One clear message, one clear action

**Rule:** Every element should move visitor toward CTA. If not, delete it.

---

### Tip 3: Steal Like an Artist

**Study successful landing pages:**
- Stripe.com (B2B, clean, developer-focused)
- Superhuman.app (Aspirational, premium feel)
- Linear.app (Modern, minimalist)
- Notion.so (Versatile, clear value prop)

**Tool:** https://land-book.com (Landing page gallery)

**Don't copy exactly.** Understand WHY it works, adapt to your product.

---

### Tip 4: Video > Screenshot

**Stats:**
- Landing pages with video: 86% higher conversion
- Loom demo video (30-60 seconds) >> Static images

**What to show:**
1. Problem (10 seconds)
2. Solution walkthrough (30 seconds)
3. CTA (5 seconds)

**Tools:**
- Loom: https://loom.com
- Screen Studio: https://screen.studio (Beautiful screen recordings)

---

### A/B Testing Ideas

**Test 1: Headline**
- A: "Schedule meetings without the back-and-forth"
- B: "Save 5 hours per week on meeting coordination"
- Winner: B (Specific outcome > Generic benefit)

**Test 2: CTA Button**
- A: "Get Started"
- B: "Start Free Trial"
- Winner: B (Removes uncertainty)

**Test 3: Pricing Display**
- A: Show all 3 plans equally
- B: Highlight "Most Popular" plan
- Winner: B (Anchor effect)
