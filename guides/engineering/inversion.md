# 🔄 Tư duy ngược (Inversion Thinking)

## 1. Đảo ngược vấn đề (Invert, always invert) - Carl Jacobi
Thay vì hỏi "Làm thế nào để thành công?", hãy hỏi "Làm thế nào để thất bại?" và tránh những điều đó.
*   **Đầu tư:** Làm sao để mất sạch tiền? (Dùng đòn bẩy cao, mua theo tin đồn, không cắt lỗ). -> Tránh 3 cái này, bạn sẽ khó mà nghèo được.
*   **Hôn nhân:** Làm sao để ly dị? (Không giao tiếp, ngoại tình, khinh thường nhau). -> Tránh nó.
*   **Sức khỏe:** Làm sao để chết sớm? (Hút thuốc, ngồi lì một chỗ, ăn đồ chiên rán). -> Đừng làm vậy.

## 2. Via Negativa (Cải thiện bằng cách loại bỏ) - Nassim Taleb
Chúng ta thường nghĩ cải thiện là thêm vào (Thêm tính năng, uống thêm thuốc bổ, mua thêm đồ). Nhưng kỹ thuật tối ưu thường là **bớt đi**.
*   **Code:** Code ít dòng hơn mà vẫn chạy đúng là code xịn. (Less code = Less bugs).
*   **Sức khỏe:** Bỏ đường, bỏ thuốc lá hiệu quả hơn uống vitamin.
*   **Tài chính:** Cắt giảm chi tiêu lãng phí dễ hơn kiếm thêm thu nhập.

## 3. Phân tích nguyên nhân gốc rễ (Root Cause Analysis - 5 Whys)
Khi hệ thống hỏng, đừng chỉ dán băng keo (Fix triệu chứng). Hãy hỏi "Tại sao?" 5 lần để tìm nguyên nhân gốc.
*   **Ví dụ:** Máy hỏng.
    1.  Tại sao? -> Cầu chì cháy.
    2.  Tại sao? -> Quá tải điện.
    3.  Tại sao? -> Trục máy bị kẹt.
    4.  Tại sao? -> Thiếu dầu bôi trơn.
    5.  Tại sao? -> Bơm dầu bị hỏng. -> **Thay bơm dầu (Gốc rễ), chứ không chỉ thay cầu chì.**
