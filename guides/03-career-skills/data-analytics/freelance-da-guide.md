# 🌍 Freelance Data Analyst Playbook (Upwork/Fiverr 2026)

## 1. Chuẩn bị nền tảng

| Hạng mục | Checklist |
| --- | --- |
| **Portfolio** | 3 dự án mô tả rõ vấn đề → giải pháp → impact; include dashboard link/demo video |
| **Case Studies** | Viết blog/Medium hoặc GitHub README tường thuật từng dự án |
| **Branding** | Ảnh profile chuyên nghiệp, headline rõ "Data Analyst | SQL | Tableau" |
| **Tooling** | Thành thạo SQL, Excel/Google Sheets, Tableau/Power BI, Python cơ bản |

## 2. Lập hồ sơ trên Upwork/Fiverr

1. Keyword: “Data Analyst”, “Dashboard”, “Looker Studio”, “Marketing Analytics”.
2. Intro video 60–90s: giới thiệu kinh nghiệm, phong cách làm việc, CTA rõ.
3. Gói dịch vụ mẫu (Fiverr):
    - Starter: 1 dashboard 3 chart – $150 – 3 ngày.
    - Standard: Dashboard + data cleaning – $300 – 5 ngày.
    - Premium: KPI dashboard + training session – $600 – 7 ngày.

## 3. Chiến lược săn job

- **Upwork Job Feed:** lọc project < 5 proposal, reply trong 30 phút đầu.
- **Template proposal 3 đoạn:**
    1. Nêu hiểu vấn đề (quote keyword từ job).
    2. Kinh nghiệm tương tự + link portfolio.
    3. Đề xuất bước tiếp theo (call 15 phút) + cam kết SLA.
- **Outbound LinkedIn:** Viết bài chia sẻ case study, gắn call-to-action nhận dự án.

## 4. Quy trình thực thi

| Bước | Mô tả |
| --- | --- |
| 1. Discovery Call | 15 phút để xác định KPI, nguồn dữ liệu, timing |
| 2. Proposal & Scope | Gửi Miro board hoặc document: deliverable, timeline, giá |
| 3. Data Intake | Checklist định dạng, bảo mật, access control |
| 4. Build & Review | Gửi demo Loom, nhận feedback, iterate |
| 5. Handover | Training video + doc hướng dẫn + support 7 ngày |

## 5. Pricing & Upsell

- **Hourly:** $25–$60 (global), 300k–1.2M VND/h (VN).
- **Project-based:** 10–15% tổng budget marketing/ops liên quan.
- **Retainer:** 1–2k USD/tháng cho 1–2 dashboard + weekly check-in.
- Upsell thêm: Data Quality audit, KPI review hàng quý, training nội bộ.

## 6. Quản lý rủi ro

- Hợp đồng nêu rõ scope, số vòng chỉnh sửa, điều khoản bảo mật.
- Thu 30–50% deposit trước khi bắt đầu.
- Dùng tool quản lý nhiệm vụ (Notion, Asana) chia sẻ với khách hàng.
- Backup dữ liệu và script trên GitHub private/Drive.

## 7. Nâng cấp kỹ năng

- Học thêm **Looker Studio connectors**, **Supermetrics**, **dbt Cloud** để mở rộng dịch vụ.
- Tham gia cộng đồng (Locally Optimistic, Measure Slack) để cập nhật nhu cầu thị trường.
- Theo dõi chỉ số cá nhân: tỷ lệ win proposal, giá trung bình/project, NPS khách hàng.

> 💬 *Pro tip:* Sau mỗi dự án, xin testimonial + case study (cho phép ẩn dữ liệu nhạy cảm) để tăng uy tín và tăng giá ở dự án tiếp theo.
