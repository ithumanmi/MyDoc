# ⚖️ Data Scientist vs Data Analyst (2026)

> Chọn path phù hợp dựa trên thế mạnh, sở thích và nhu cầu của công ty.

## 1. Khác biệt tổng quan

| Tiêu chí | Data Analyst | Data Scientist |
| --- | --- | --- |
| **Tập trung** | Business intelligence, phân tích mô tả & chẩn đoán | Mô hình dự đoán, ML, tối ưu hóa |
| **Output** | Dashboard, báo cáo, insight action | Model, pipeline ML, API, tối ưu tự động |
| **Stakeholder chính** | Business, Product, Marketing | Engineering, Product, AI/ML team |
| **Thời gian triển khai** | 1–4 tuần / dự án ngắn | 1–3 tháng (R&D, tuning) |

## 2. Kỹ năng so sánh

| Domain | Analyst | Scientist |
| --- | --- | --- |
| **SQL & BI** | Thành thạo SQL, Power BI/Tableau | Cần biết nhưng không phải trọng tâm |
| **Coding** | Python/R cơ bản cho EDA | Python advanced, ML libs (scikit-learn, PyTorch) |
| **Math/Stats** | Thống kê mô tả, test giả thuyết | Xác suất nâng cao, optimization, linear algebra |
| **ML/AI** | Áp dụng model đơn giản (regression) nếu cần | Thiết kế, huấn luyện, deploy ML model |
| **Communication** | Storytelling cho business | Giải thích model cho stakeholder kỹ thuật & business |

## 3. Stack & Toolchain

| Layer | Analyst | Scientist |
| --- | --- | --- |
| Data Prep | dbt, SQL, Excel, PowerQuery | dbt, Spark, Pandas/Polars |
| Visualization | Power BI, Tableau, Looker Studio | Python notebooks, Streamlit, custom viz |
| Modeling | Excel, Statsmodels | scikit-learn, TensorFlow/PyTorch, MLflow |
| Deployment | Slides, dashboards | APIs, batch jobs, feature store |

## 4. Khi nào chọn vai trò nào?

| Nếu bạn… | Phù hợp Analyst | Phù hợp Scientist |
| --- | --- | --- |
| Thích tương tác business, kể chuyện dữ liệu | ✅ | ⚪ |
| Muốn đào sâu ML, tối ưu thuật toán | ⚪ | ✅ |
| Muốn thấy tác động nhanh vào KPI | ✅ | ⚪ |
| Muốn xây sản phẩm dữ liệu dài hạn | ⚪ | ✅ |
| Thoải mái với coding nặng & math | ⚪ | ✅ |

## 5. Lộ trình chuyển đổi

### Analyst → Scientist
1. Tăng cường Python, OOP, Git, test.
2. Học linear algebra, calculus cơ bản, ML theory (Andrew Ng / FastAI).
3. Làm project ML end-to-end (ETL → Training → Deploy via FastAPI).
4. Tham gia đội ngũ ML trong công ty hoặc freelancing nhỏ để lấy kinh nghiệm.

### Scientist → Analyst/Decision Scientist
1. Rèn storytelling, quản trị stakeholder.
2. Học thêm finance/business để nối dữ liệu với KPI.
3. Làm side project BI, tham gia workshop về executive communication.

## 6. Compensation & thị trường

- **Analyst:** 18–60M VND/tháng tùy cấp; global 80k–150k USD (Mid/Senior).
- **Scientist:** 30–120M VND/tháng; global 110k–200k USD.
- Chọn theo nhu cầu thị trường: startup ưu tiên Analyst nhanh nhẹn; enterprise/SaaS cần Scientist để xây sản phẩm dữ liệu.

## 7. Checklist tự đánh giá

| Câu hỏi | Analyst | Scientist |
| --- | --- | --- |
| Tôi có thể kể lại insight cho CEO trong 5 phút? | ✅ | ⚪ |
| Tôi hiểu lifecycle của model từ thu thập dữ liệu đến monitoring? | ⚪ | ✅ |
| Tôi biết cách chọn KPI phù hợp cho business team? | ✅ | ⚪ |
| Tôi tự tin tuning hyperparameter/feature engineering? | ⚪ | ✅ |

> 🔁 *Tip:* Bạn có thể phát triển hybrid “Decision Scientist”, kết hợp storytelling của Analyst và modeling của Scientist, rất hợp với Product/Strategy team.
