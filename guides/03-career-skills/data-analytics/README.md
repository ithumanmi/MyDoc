# 📊 Data Analytics Career & Decision Intelligence Guide

> [← Back to Guides](../../README.md) | [Home](../../../README.md)

**Audience:** Junior/Mid Data Analyst, Business Analyst chuyển ngành, Decision Intelligence practitioner.

**Bạn sẽ nhận được:**

- Lộ trình nghề nghiệp + benchmark kỹ năng mỗi cấp.
- Checklist xây portfolio, vượt phỏng vấn và xử lý assignment.
- Tư duy Decision Intelligence: từ First Principles tới Executive Communication.
- Sprint 30 ngày để luyện SQL, storytelling, audit năng lực.

> ⏱️ **Time to Action:** 4 tuần, 6–8h/tuần theo kế hoạch ở mục 6.

Dữ liệu không chỉ là con số, nó là ngôn ngữ của sự thật trong kinh doanh. Phần hướng dẫn này tập trung vào cách xây dựng sự nghiệp thành công và ra quyết định thông minh dựa trên dữ liệu (**Decision Intelligence**).

## 🚀 5. Emerging Roles & Tooling 2026

| Vai trò/Tool | Khi nào cần | Gợi ý học nhanh |
| --- | --- | --- |
| **Analytics Engineer** | Khi cần chuẩn hóa transformation/dbt, đảm bảo dữ liệu sạch cho BI | dbt Fundamentals, Data Build Tool docs, [Meltano](https://meltano.com/) pipelines |
| **Decision Scientist** | Khi đội cần người kết nối Product x Data x Strategy | Học causal inference cơ bản + storytelling, tham khảo Meta/Google Decision Scientist JD |
| **AI-assisted Analyst** | Khi dùng LLM để tăng tốc query, QA dashboard | Thử [Snowflake Cortex](https://www.snowflake.com/) / [Hex Magic](https://hex.tech/), xây prompt chuẩn hóa |
| **Modern BI Stack** | Looker, Lightdash, Sigma, ThoughtSpot | Làm mini project chuyển dashboard Excel sang BI self-service |

> ⚙️ **Tooling trend:** kết hợp `dbt + DuckDB/Polars + Hex/Streamlit` cho pipeline nhẹ, `Lakehouse + Semantic Layer (MetricFlow)` cho doanh nghiệp lớn.

## 🗓️ 6. 30-Day Learning Sprint

| Tuần | Focus | Deliverable |
| --- | --- | --- |
| **Week 1 - Foundation Refresh** | Ôn SQL nâng cao (window functions), xác suất, đọc lại First Principles | Notebook chứa 3 bài SQL khó + note bias |
| **Week 2 - Portfolio Upgrade** | Chọn 1 dự án cũ, thêm metric mới, viết README storytelling | Repo mới hoặc update Tableau Public + checklist đạt chuẩn |
| **Week 3 - Decision Intelligence** | Thực hành OODA/ICE với case marketing, viết bản memo 1 trang | Memo 1 pager gửi mentor/đồng nghiệp feedback |
| **Week 4 - Interview & Audit** | Làm Knowledge Audit + mock interview, review kết quả | Điểm audit + plan cải thiện đăng vào Daily Log |

> 📓 *Weekly Ritual:* Cuối tuần, review tiến độ trong [Weekly Review](../../../templates/weekly-review.md), ghi học được gì và kế hoạch tuần sau.
