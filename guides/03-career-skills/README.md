## 🧭 Cách sử dụng
1. Chấm điểm nhanh bằng **Career Skill Audit**.
2. Dựa vào điểm yếu → chọn giai đoạn (G1-G4) cần củng cố.
3. Theo roadmap của giai đoạn đó, kết hợp checklist/bài tập trong từng file.
4. Mỗi quý quay lại audit lại và cập nhật đường đi.
