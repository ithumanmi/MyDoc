# 🎓 Data Enablement Session Plan

> Template 90 phút cho workshop Data Literacy / Self-serve BI.

## 1. Session Overview

- **Audience:** Business users/Product/Ops
- **Goal:** Nắm KPI chính, thao tác trên dashboard, đặt câu hỏi tốt
- **Format:** 90 phút (60’ training + 30’ hands-on)
- **Prerequisite:** Tài khoản BI tool, dataset demo, KPI glossary

## 2. Agenda (90’)

| Thời gian | Nội dung | Người phụ trách |
| --- | --- | --- |
| 0–10’ | Ice-breaker & mục tiêu buổi học | Facilitator |
| 10–25’ | Metric tree & KPI recap | Data Lead |
| 25–45’ | Demo dashboard: cách dùng filter, drilldown | BI Analyst |
| 45–75’ | Hands-on exercise (case thực tế) | Participants + mentor support |
| 75–85’ | Present kết quả + “So what?” | Nhóm học viên |
| 85–90’ | Recap, survey nhanh, giao bài tập follow-up | Facilitator |

## 3. Materials & Prep Checklist

- [ ] Slide deck (overview KPI, hướng dẫn dashboard)
- [ ] Demo dataset + sample questions
- [ ] Access list & permissions chuẩn bị sẵn
- [ ] Mentor list (tỷ lệ 1 mentor : 5 học viên)
- [ ] Feedback form (Google Form/Typeform)

## 4. Hands-on Exercise Template

| Bước | Mô tả |
| --- | --- |
| 1. Tình huống | Ví dụ: “Tăng retention D7 thêm 5% trong Q2” |
| 2. KPI cần kiểm tra | Các metric liên quan (DAU, conversion funnel, cohort) |
| 3. Task | Tìm root-cause, đề xuất hành động, ghi insight 3 bullet |
| 4. Deliverable | Slide 2 trang hoặc note trong template Notion |

## 5. Follow-up

- Gửi recap email + recording + tài liệu tham khảo trong 24h
- Giao bài tập nhỏ (ví dụ: tự chạy 1 truy vấn/ dashboard screenshot)
- Theo dõi completion rate và câu hỏi phát sinh trong #ask-data

> 📌 *Tip:* Luôn gắn case thực tế của phòng ban để tăng tính liên quan, đồng thời ghi nhận “Data Hero” nổi bật trong buổi học.
