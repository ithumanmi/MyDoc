## 1. Career Levels Overview

### The Ladder

```
👑 Lead/Principal Engineer (7-10+ YOE)
      ↑
🎖️ Senior Game Developer (4-7 YOE)
      ↑
⚔️ Mid-Level Game Developer (2-4 YOE)
      ↑
🐣 Junior Game Developer (0-2 YOE)
      ↑
🌱 Intern/Fresher (0 YOE)
```

---

### Salary Ranges (Vietnam Market 2026)

| Level | Years | VND/month | USD/month | Total/year (USD) |
|-------|-------|-----------|-----------|------------------|
| **Intern** | 0 | 3-6M | $120-$240 | $1.5k-$3k |
| **Junior** | 0-2 | 8-15M | $320-$600 | $4k-$7k |
| **Mid** | 2-4 | 15-30M | $600-$1200 | $7k-$15k |
| **Senior** | 4-7 | 30-50M | $1200-$2000 | $15k-$25k |
| **Lead** | 7-10 | 50-80M | $2000-$3200 | $25k-$40k |
| **Principal** | 10+ | 80M+ | $3200+ | $40k+ |

**Note:** Big companies (VNG, Amanotes) trả cao hơn 20-30%. Startups thấp hơn nhưng có equity.

---

### Skill Matrix

| Skill | Junior | Mid | Senior | Lead |
|-------|--------|-----|--------|------|
| **Technical** | Basic Unity, C# | Advanced patterns, 3D/Multiplayer | Architecture, Performance | Strategy, Tech vision |
| **Ownership** | Tasks | Features | Systems | Products |
| **Impact** | Self | Team | Department | Company |
| **Mentoring** | None | 1-2 juniors | 3-5 devs | Entire team |
| **Communication** | Team | Stakeholders | Execs | Public |

## 2. Junior Game Developer (0-2 YOE)

### 🎯 Mục tiêu

**Main Goal:** Học → Execute → Deliver quality features.

---

### 📚 Skills Required

#### **A. Technical (Core)**

**Unity:**
- MonoBehaviour lifecycle (Awake, Start, Update, FixedUpdate)
- Prefabs, Scenes, Asset management
- Input System (Legacy hoặc New)
- Physics 2D/3D (Rigidbody, Colliders)
- UI (uGUI hoặc UI Toolkit)

**C#:**
- OOP (Classes, Inheritance, Interfaces)
- Collections (List, Dictionary, Array)
- Coroutines, Async/Await
- LINQ basics

**Version Control:**
- Git (Clone, Commit, Push, Pull, Merge)
- Unity YAML merge

---

#### **B. Soft Skills**

- **Ask good questions:** "I tried X, got error Y. Could you help?"
- **Document learnings:** TIL (Today I Learned) journal
- **Meet deadlines:** Thà báo sớm "cần thêm 1 ngày" hơn là deliver muộn

---

### 💼 Typical Tasks

- Implement features theo design doc (VD: "Add jump mechanic")
- Fix bugs assigned by Lead
- Write unit tests cho functions
- Tạo prefabs, scenes theo hướng dẫn

---

### 📈 Promotion Criteria: Junior → Mid (18-24 tháng)

**✅ Checklist:**
- [ ] Hoàn thành 100% tasks on time (3 tháng liên tục)
- [ ] Code quality tốt (ít bugs, readable, commented)
- [ ] Tự giải quyết 80% vấn đề (không hỏi liên tục)
- [ ] Đóng góp ideas trong meetings
- [ ] Học thêm 1 skill mới (VD: Shaders, Multiplayer basics)

**Portfolio Evidence:**
- Ship ít nhất 1 game/feature lớn
- GitHub có 3+ personal projects

---

### 💡 Tips for Juniors

**DO:**
- ✅ Over-communicate: Update tiến độ daily
- ✅ Learn from code reviews (Đừng defensive)
- ✅ Build side projects (Show initiative)
- ✅ Attend company game jams

**DON'T:**
- ❌ Chờ được giao việc (Proactive tìm task)
- ❌ Reinvent the wheel (Hỏi trước khi code from scratch)
- ❌ Afraid of asking "dumb questions" (Better than stuck 3 days)

## 3. Mid-Level Game Developer (2-4 YOE)

### 🎯 Mục tiêu

**Main Goal:** Own features → Mentor juniors → Improve team velocity.

---

### 📚 Skills Required

#### **A. Technical (Advanced)**

**Architecture:**
- Design Patterns (Singleton, Observer, Command, Object Pool)
- Separation of Concerns (MVC, MVP)
- ScriptableObject-driven design

**Performance:**
- Profiler (CPU, GPU, Memory)
- Object Pooling
- Coroutine optimization
- Draw call batching

**Specialized (Pick 1-2):**
- **3D:** Shader basics, Lighting (Baked vs Realtime), LOD
- **Multiplayer:** Netcode/Mirror basics, Client-server architecture
- **Mobile:** APK size optimization, Battery usage, Touch controls

---

#### **B. Soft Skills**

- **Mentoring:** Hướng dẫn juniors (Code reviews, pair programming)
- **Estimation:** Đưa timeline chính xác (với buffer)
- **Stakeholder management:** Explain technical constraints cho non-tech

---

### 💼 Typical Tasks

- Own end-to-end features (VD: "Inventory System")
- Design system architecture (với oversight từ Senior)
- Code review cho juniors
- Optimize performance bottlenecks
- Onboard new team members

---

### 📈 Promotion Criteria: Mid → Senior (24-36 tháng)

**✅ Checklist:**
- [ ] Ship 2+ major features (with design ownership)
- [ ] Mentor 2+ juniors successfully (They get promoted)
- [ ] Solve critical production issues independently
- [ ] Contribute to team processes (CI/CD, code standards)
- [ ] Present work internally (Lunch & Learn, Knowledge sharing)

**Technical Depth:**
- Master 1 specialty (VD: "Expert trong Unity Multiplayer")
- Contribute to open source (Hoặc Unity forums, Stack Overflow)

---

### 💡 Tips for Mid-Level

**DO:**
- ✅ Think beyond code: "Giải pháp này scale được không?"
- ✅ Document decisions: Architecture Decision Records (ADR)
- ✅ Propose improvements: "Feature X có thể làm theo pattern Y"
- ✅ Build personal brand (Blog, YouTube, LinkedIn)

**DON'T:**
- ❌ Be a "code monkey" (Chỉ code không suy nghĩ)
- ❌ Gatekeep knowledge (Share rộng rãi)
- ❌ Ignore business context (Hiểu sao PM cần feature này)

---

## 4. Senior Game Developer (4-7 YOE)

### 🎯 Mục tiêu

**Main Goal:** Architect systems → Multiply team → Technical leadership.

---

### 📚 Skills Required

#### **A. Technical (Expert)**

**System Design:**
- Design scalable architectures (Modular, Testable, Maintainable)
- Trade-off analysis (Performance vs Maintainability vs Time)
- Technical debt management

**Tools & Processes:**
- CI/CD for Unity (Jenkins, GitHub Actions)
- Automated testing (Unity Test Framework, NUnit)
- Profiling & Debugging advanced (Memory leaks, Threading issues)

**Cross-discipline:**
- Work with Artists (Understand constraints: Poly count, Texture size)
- Work with Designers (Implement complex mechanics)
- Work with Backend (API integration, Server logic)

---

#### **B. Soft Skills**

- **Technical Writing:** RFCs (Request for Comments), Architecture docs
- **Negotiation:** Push back on unrealistic timelines
- **Influence:** Convince team về technical decisions
- **Public Speaking:** Conference talks, Meetups

---

### 💼 Typical Tasks

- Design core game systems (Save/Load, Progression, Multiplayer)
- Code review entire team (Enforce standards)
- Interview candidates (Technical assessment)
- Strategic technical planning (Q1 roadmap: Tech debt vs Features)
- Firefight production incidents (Critical bugs, server crashes)

---

### 📈 Promotion Criteria: Senior → Lead (36-48 tháng)

**✅ Checklist:**
- [ ] Ship 1+ game from prototype → launch (End-to-end ownership)
- [ ] Define team coding standards & architecture
- [ ] Mentor 3+ developers (Mid → Senior)
- [ ] Recognized externally (Conference speaker, Open source maintainer)
- [ ] Drive technical initiatives (VD: Migrate to URP, Implement DOTS)

**Business Impact:**
- Deliver features faster (Team velocity tăng 30%+)
- Reduce bugs in production (Stability metrics improve)

---

### 💡 Tips for Seniors

**DO:**
- ✅ Think 6-12 months ahead (Tech roadmap)
- ✅ Unblock team (Remove bottlenecks, not do all work yourself)
- ✅ Say NO strategically ("Feature X sẽ tech debt, suggest refactor first")
- ✅ Build relationships cross-team (PM, Design, QA, DevOps)

**DON'T:**
- ❌ Be a bottleneck (Review code trong 24h, không chờ 1 tuần)
- ❌ Perfectionism (Shipping > Perfect code)
- ❌ Ivory tower (Code hands-on regularly, don't just architect)

---

## 5. Lead/Principal (7+ YOE)

### 🎯 Mục tiêu

**Main Goal:** Product success → Team growth → Company impact.

---

### 📚 Skills Required

#### **A. Technical (Strategic)**

- **Technology Vision:** "3 năm tới nên invest vào AI, Cloud gaming hay VR?"
- **Vendor evaluation:** Evaluate third-party tools (Unity vs Unreal, Photon vs Custom server)
- **Cost optimization:** Balance cloud costs vs performance

---

#### **B. Leadership**

- **Hiring:** Build team từ 0 → 10+ people
- **Retention:** Keep top performers happy
- **Career development:** Customize growth plans cho từng dev
- **Conflict resolution:** Mediate technical disagreements

---

### 💼 Typical Tasks

- Define technical strategy (OKRs, Roadmap)
- Represent Engineering trong exec meetings
- Partner với Product/Design leads
- Build processes (Sprint planning, Retros, On-call rotation)
- Crisis management (Game launch crashes, server DDoS)

---

### 📈 Promotion Criteria: Lead → Principal/Director

**✅ Checklist:**
- [ ] Lead team ship multiple successful games
- [ ] Hire & grow 10+ engineers
- [ ] Establish technical culture (Code quality, Innovation, Learning)
- [ ] Recognized industry-wide (Speaker, Author, Thought leader)
- [ ] Drive revenue (Features directly impact KPIs)

---

### 💡 Leadership Philosophy

**Great Leads:**
- **Servant Leadership:** Serve team, not command
- **Delegate:** Trust team, don't micromanage
- **Transparent:** Share context (Why this feature? What's company goal?)
- **Accountable:** Failures = your responsibility, Successes = team's credit

## 6. Promotion Strategy

### A. Promotion là gì?

**Promotion ≠ Thăng chức tự nhiên sau X năm.**

**Promotion = Chứng minh bạn đã làm việc ở level tiếp theo.**

---

### B. The "Glue Work" Problem

**Glue Work:** Công việc cần thiết nhưng không "flashy" (Code reviews, Mentoring, Docs).

**Vấn đề:** Juniors làm Glue Work → Không còn thời gian build technical skills → Stuck.

**Solution:**
- **70% visible impact** (Ship features, Fix critical bugs)
- **30% glue work** (Help team, Process improvement)

---

### C. Promotion Playbook (6-Month Sprint)

#### **Month 1-2: Gather Evidence**
- [ ] List achievements (Features shipped, Bugs fixed, Impact metrics)
- [ ] Get feedback từ peers, manager (360 review)
- [ ] Identify gaps vs next level (Compare skill matrix)

#### **Month 3-4: Close Gaps**
- [ ] Upskill (Courses, Side projects)
- [ ] Take on stretch assignments (Lead 1 feature end-to-end)
- [ ] Increase visibility (Present at team meetings)

#### **Month 5: Document & Pitch**
- [ ] Write **Promotion Packet:** (See template below)
- [ ] Schedule 1:1 với manager để discuss

#### **Month 6: Negotiation**
- [ ] Present packet formally
- [ ] Negotiate salary (See Section 7)
- [ ] If rejected: Get written plan với timeline

---

### D. Promotion Packet Template

```markdown
# Promotion Proposal: [Your Name] - [Current Level] → [Target Level]

## Summary
I'm requesting promotion to [Level] based on [X] months of performance 
at the next level.

## Evidence

### Impact
- **Feature X:** Shipped on time, increased DAU by 15%
- **Bug Y:** Fixed critical crash affecting 10k users
- **Metrics:** Team velocity increased 20% (Q1 → Q2)

### Skills Demonstrated
- [Skill 1]: Example (Code, PR, Project)
- [Skill 2]: Example
- [Skill 3]: Example

### Mentoring
- Mentored [Name] - promoted to Mid-level
- Led 5 code reviews/week

### Peer Feedback
> "[Your Name] consistently delivers high-quality work and helps 
> the team..." - [Peer Name]

## Why Now?
- I've operated at [Next Level] for [X] months
- [Company] benefits: [Specific value I bring]
- Market rate research: [Levels.fyi data]

## Proposed Compensation
- Current: $X
- Target: $Y (Market median for [Level])
- Justification: [Achievements + Market data]
```

## 7. Salary Negotiation

### A. Research First

**Tools:**
- **Levels.fyi:** Crowdsourced salary data
- **Glassdoor:** Company-specific
- **ITviec Salary Report:** Vietnam market
- **Network:** Hỏi bạn bè (Anonymously)

---

### B. Negotiation Framework (From Game Theory Guide)

**1. BATNA (Best Alternative):**
- Offer từ company khác?
- Freelance income?
- Comfortable ở mức hiện tại?

**2. Anchoring:**
- **Employer hỏi trước:** "Budget is 20M VND"
  - You: "Based on my experience and market rate (25M), I'm looking at 23-25M."

- **You anchor:** "I'm targeting 25M based on [Evidence]"
  - Sets high baseline

**3. Framing:**
- ❌ "Tôi cần thêm tiền vì sắp cưới" (Personal need)
- ✅ "I've shipped [X features], market rate for my level is [Y]" (Value-based)

---

### C. Negotiation Script

```
Manager: "We can offer 18M VND"

You: "I appreciate the offer. I've done some research and the market 
rate for [Level] with my skillset (Unity, Multiplayer, 4 YOE) is 22-25M. 

Given that I've:
- Shipped [Game X] end-to-end
- Reduced bugs by 30%
- Mentored 2 juniors

I was hoping we could meet at 23M. Is that feasible?"

[If NO]
You: "I understand there are budget constraints. Can we structure it as:
- 20M base
- 3M performance bonus (tied to KPIs)
- Review in 6 months?"
```

---

### D. Non-Salary Negotiables

If salary stuck, negotiate:
- **Equity/Stock options** (Startups)
- **Signing bonus** (One-time 5-10M VND)
- **Remote work** (Save commute time/cost)
- **Learning budget** ($1000/year for courses)
- **Title bump** (Senior title helps future job search)

---

### E. When to Walk Away

**Red Flags:**
- Offer < 80% market rate với no explanation
- Company refuses to discuss numbers (Opacity)
- Toxic culture (glassdoor reviews 2-3 stars)

**Your leverage:** Always be applying (Interviews = BATNAs).

## 8. When to Switch Companies

### A. Stay or Leave?

**Stay if:**
- ✅ Learning rapidly (New challenges every quarter)
- ✅ Clear growth path (Manager supports promotion)
- ✅ Compensation fair (Within 10% of market)
- ✅ Like team/culture
- ✅ Equity vesting (Golden handcuffs)

**Leave if:**
- ❌ Stagnant (Same work 12+ months)
- ❌ No promotion despite performance (Blocked)
- ❌ Underpaid (>20% below market)
- ❌ Toxic environment
- ❌ Company dying (Layoffs, revenue drop)

---

### B. Job Hopping Frequency

**Optimal:**
- **Junior:** 1.5-2 years (Learn fundamentals first)
- **Mid:** 2-3 years (Build track record)
- **Senior:** 3-5 years (Strategic moves)

**Too fast (<1 year):** Red flag "job hopper"  
**Too slow (>5 years same company):** Miss salary growth (Switching = 20-30% raise)

---

### C. Interview Prep

**LeetCode (Optional for Game Dev):**
- Focus: Data structures (Arrays, Trees, Graphs)
- 20-30 Easy/Medium problems (VNG, Amanotes ask coding)

**Portfolio Review:**
- Prepare to live-code 1 simple feature (VD: "Implement jump")
- Explain architecture decisions

**Behavioral (STAR Method):**
```
Situation: [Context]
Task: [Challenge]
Action: [What you did]
Result: [Outcome với metrics]
```

**Example:**
- **Situation:** "Game was crashing for 20% of Android users."
- **Task:** "Debug và fix trong 48h before launch."
- **Action:** "Used Profiler → Found memory leak trong sprite loading. Implemented Object Pool."
- **Result:** "Crash rate dropped to 1%. Game launched successfully, 100k downloads Week 1."

## 🎯 Success Stories (Vietnam)

### Case Study 1: Junior → Senior in 3.5 Years

**Profile:**
- **Start:** Junior Unity Dev @ Startup (10M VND)
- **Actions:**
  - Shipped 2 games (Hyper-casual → RPG)
  - Built YouTube channel (5k subs, Unity tutorials)
  - Contributed to Unity open-source projects
  - Switched companies at Year 2 (15M → 22M)
  - Promoted to Senior at Year 3.5 (35M)

**Key:** Side projects + Content creation = Visibility.

---

**Profile:**
- **Start:** Mid-Level @ VNG (20M VND)
- **Actions:**
  - Led multiplayer integration (10M CCU game)
  - Mentored 5 juniors (3 promoted)
  - Spoke at GameDev Conference
  - Internal promotion to Lead at Year 4 (50M + equity)

**Key:** Mentoring + Public speaking = Leadership signal.

## 🎯 Kết luận

**Career growth không phải đường thẳng:**
- Có plateaus (6-12 tháng không tiến bộ).
- Có setbacks (Projects fail, promotions denied).

**Formula for success:**
```
Skill Growth + Impact + Visibility + Timing = Promotion
```

**Actionable Next Steps:**
1. **Đánh giá hiện tại:** Bạn đang ở level nào? (Honest assessment)
2. **Xác định mục tiêu:** Muốn đến level nào trong 1-2 năm?
3. **Close gaps:** Skills/Projects/Network cần thiết?
4. **Execute:** 6-month promotion sprint (Section 6C)
5. **Iterate:** Nếu fail → Learn → Retry hoặc Switch company.

**Chúc bạn thành công! 🚀**
