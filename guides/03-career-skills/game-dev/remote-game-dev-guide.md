## 1. Why Remote Game Dev?

### Lợi ích

**💰 Financial:**
| Metric | VN Company | Remote (Asia) | Remote (US/EU) |
|--------|------------|---------------|----------------|
| **Junior** | $400-600/m | $1000-1500/m | $2000-3000/m |
| **Mid** | $800-1200/m | $2000-3000/m | $4000-6000/m |
| **Senior** | $1500-2000/m | $4000-6000/m | $8000-12000/m |

**Multiplier:** 2-5x lương Việt Nam với cùng cost of living!

**🌍 Career:**
- Work với top talent toàn cầu
- Ship games có reach hàng triệu users
- Modern tech stack (Latest Unity/Unreal versions)
- Better work-life balance (Many remote companies 4-day workweek)

---

### Thách thức

**⏰ Timezone:**
- US: 12-15h chênh lệch → Work nights (8pm-12am VN)
- EU: 5-7h chênh lệch → Dễ hơn (Overlap 9am-12pm VN)

**🗣️ English:**
- Daily standups, code reviews, design discussions
- Need fluency, not just "reading docs"

**🏢 Culture:**
- Async communication (Slack, Notion, Loom videos)
- Self-directed work (Ít micromanage)
- High accountability

## 2. Market Reality

### A. Game Industry Remote Landscape

**Good News:**
- Covid accelerated remote adoption
- Indie studios đã remote từ lâu
- Tools matured (Unity Collaborate, Perforce remote)

**Bad News:**
- **AAA studios:** Ít remote hơn (Cần in-office cho artists/designers sync)
- **Junior positions:** Hiếm (Companies prefer onsite training)
- **Competition:** Toàn cầu (Compete với devs từ Poland, Brazil, India)

---

### B. Best Niches for Remote

**✅ High Demand (Remote-friendly):**

1. **Game Server/Backend Engineer**
   - Multiplayer games cần server devs
   - Tech: C#/Go/Rust + Docker/Kubernetes
   - **Overlap với Backend role** → Dễ switch

2. **Tools/Pipeline Engineer**
   - Build Unity/Unreal editor tools
   - CI/CD for game builds
   - Less need for artist collaboration

3. **Mobile Game Developer**
   - Hyper-casual, Puzzle games
   - Can work independently
   - Many remote studios (Voodoo, Kwalee)

4. **Technical Artist**
   - Shaders, VFX, Optimization
   - Bridge artist-engineer
   - High demand, low supply

5. **Web3/Blockchain Games**
   - New industry, fully remote
   - High pay ($100k-$200k)
   - Need crypto knowledge

**❌ Lower Demand (Harder remote):**
- Gameplay programmer (Need designer sync)
- Level designer (Cần real-time feedback từ artists)
- Junior generalist (Companies muốn train in-office)

## 3. Requirements & Preparation

### A. Technical Skills (Must-Have)

#### **For Unity Developer:**

**Core:**
- [ ] Unity 2022+ LTS (Biết tính năng mới: URP, DOTS)
- [ ] C# advanced (async/await, LINQ, Generics)
- [ ] Design Patterns (Observer, Command, Object Pool)
- [ ] Git (Branching, Merging, Conflict resolution)

**Specialized (Pick 1-2):**
- [ ] **Multiplayer:** Netcode/Mirror/Photon (Authoritative server)
- [ ] **Mobile:** Optimization (60fps trên mid-range), Battery/Memory
- [ ] **Shaders:** Shader Graph, HLSL, URP/HDRP
- [ ] **Tools:** Editor scripting, Build automation

**DevOps (Bonus):**
- [ ] Docker (Containerize Unity builds)
- [ ] CI/CD (GitHub Actions, Jenkins)
- [ ] Cloud (AWS GameLift, Google Cloud)

---

#### **For Unreal Developer:**

**Core:**
- [ ] Unreal 5+ (Nanite, Lumen basics)
- [ ] C++ (Smart pointers, Templates, STL)
- [ ] Blueprints (Visual scripting cho rapid prototyping)
- [ ] Version control (Perforce hoặc Git LFS)

**Specialized:**
- [ ] **Multiplayer:** Replication, Server-authoritative logic
- [ ] **Graphics:** Materials, Niagara VFX
- [ ] **Gameplay:** Gameplay Ability System (GAS)

---

### B. Portfolio Requirements

**Minimum (Junior/Mid):**
- [ ] **2-3 complete games** (Itch.io playable)
- [ ] **GitHub:** Clean code, README in English
- [ ] **1 specialty showcase** (VD: "Multiplayer racing with 100 CCU")

**Ideal (Mid/Senior):**
- [ ] **1 published game** (Steam/App Store/Play Store)
- [ ] **Open source contributions** (Unity/Unreal plugins)
- [ ] **Technical blog** (Dev.to, Medium - 5+ posts)

### D. Timezone Flexibility

**Company timezone expectations:**

**US (GMT-5 to GMT-8):**
- **Overlap needed:** 4-6 hours
- **Your schedule:** 8pm-12am VN (9am-1pm US East)
- **Feasible?** Khó (Mất đời sống tối)

**EU (GMT+0 to GMT+2):**
- **Overlap:** 9am-12pm VN = 3pm-6pm EU
- **Feasible?** Tốt nhất cho VN devs

**Asia-Pacific (GMT+8 to GMT+10):**
- **Overlap:** Full working hours
- **Companies:** Singapore, Australia startups

**Async-first companies:**
- **GitLab, Basecamp, Zapier:** Communicate via Slack/Notion
- **No required overlap** (Respond trong 24h)

## 6. Interview Process

### A. Typical Stages

**1. Recruiter Screening (30 phút):**
- **Questions:**
  - "Tell me about yourself" (Elevator pitch)
  - "Why remote?" ("I thrive in async environments, proven by...")
  - "Salary expectations?" (See Section 7)
  - "Timezone flexibility?" ("I can overlap 4-6h with [Timezone]")

**Prep:**
- Research company (Glassdoor, games they shipped)
- Prepare 5 questions ("What's the team structure?")

---

**2. Technical Phone Screen (60-90 phút):**

**Format:**
- **Live coding (30-45 phút):** CoderPad/HackerRank
  - Example: "Implement A* pathfinding"
  - Example: "Optimize this script (Currently O(n²))"
  
- **Unity Q&A (15-30 phút):**
  - "What's the difference between Update và FixedUpdate?"
  - "Explain GameObject lifecycle"
  - "How would you implement object pooling?"

**Prep:**
- **LeetCode:** 20-30 Easy problems (Arrays, Trees)
- **Unity Interview Questions:** (Google "Unity interview questions")
- **Practice speaking while coding** (Explain your thinking)

---

**3. Take-Home Assignment (4-8 giờ):**

**Example tasks:**
- "Build a simple 2D platformer with 3 levels"
- "Implement multiplayer pong (2 players sync'd)"
- "Optimize this Unity project (Currently 15fps)"

**Tips:**
- [ ] **README:** Clear setup instructions
- [ ] **Code quality:** Comments, clean structure
- [ ] **Git history:** Meaningful commits (Not 1 giant commit)
- [ ] **Extras:** Unit tests, build instructions

**Time management:**
- If they say "4-8 hours", spend exactly 6-7 hours
- Don't over-engineer (Ship functional > Perfect)

---

**4. Onsite (Virtual) - 3-5 giờ:**

**Rounds:**

**a) System Design (Senior+):**
- **Question:** "Design a multiplayer game server for 100k CCU"
- **What they test:** Architecture thinking, trade-offs

**Framework:**
1. **Clarify requirements:** FPS or turn-based? Regional servers?
2. **High-level design:** Client → Load Balancer → Game Servers → DB
3. **Deep dive:** Server-authoritative logic, lag compensation
4. **Trade-offs:** Cost vs Performance, Consistency vs Availability

**Prep:**
- Read: `domains/game-dev/game-server-guide.md` (in this repo)
- Practice: Draw diagrams on whiteboard/Excalidraw

---

**b) Coding (Live):**
- Harder than phone screen
- **Example:** "Implement networked inventory system"

---

**c) Behavioral (STAR method):**

**Questions:**
- "Tell me about a time you failed"
- "Conflict with a teammate"
- "Technical decision you disagreed with"

**Template:**
```
Situation: "We were 2 weeks from launch and game crashed on 30% of devices"
Task: "I needed to find and fix the bug within 3 days"
Action: "Used Unity Profiler → Found memory leak in sprite atlas loading. 
Implemented object pooling and reduced allocations"
Result: "Crash rate dropped to <1%. Launched on time, 100k downloads Week 1"
```

**Prepare 5-7 stories** covering:
- Technical achievement
- Failure (+ What you learned)
- Teamwork/Conflict
- Leadership/Initiative

---

## 7. Salary Negotiation

### A. Research Market Rates

**Tools:**
- **Levels.fyi:** Filter "Game Developer, Remote, [YOE]"
- **Glassdoor:** Company-specific
- **Payscale.com**

**Benchmark (2026):**
| Level | Remote (Asia) | Remote (US/EU) | Total Comp |
|-------|---------------|----------------|------------|
| **Junior (0-2)** | $30k-$45k | $50k-$70k | Base + 10% equity |
| **Mid (2-4)** | $50k-$70k | $80k-$120k | Base + 15-20% equity |
| **Senior (4-7)** | $80k-$120k | $120k-$180k | Base + 20-30% equity |
| **Lead (7+)** | $120k-$180k | $180k-$250k+ | Base + Significant equity |

---

### B. When They Ask First

**Recruiter:** "What's your salary expectation?"

**Strategy 1: Deflect (Best)**
```
"I'm flexible and more interested in finding the right fit first. 
What's the budget for this role?"
```

**Strategy 2: Range (If must answer)**
```
"Based on my research for [Level] with [YOE] in [Tech], I'm looking 
at $X-$Y, depending on total comp (equity, benefits)."

(X = Market median, Y = +20%)
```

**Never:**
- ❌ Give exact number first (Anchors low)
- ❌ Reveal current salary ("I make $X" → They offer $X+10%)

---

### C. When You Get Offer

**Initial offer:** Usually 10-20% below budget (Room to negotiate)

**Response (Don't accept immediately):**
```
"Thank you for the offer! I'm excited about [Company]. 
Can I take 24-48h to review the details?"
```

**Evaluate:**
- Base salary
- Equity (%, vesting schedule)
- Benefits (Health insurance, learning budget, gear)
- Remote perks (Home office stipend, coworking space)

---

### D. Counter-Offer Script

**If offer is low:**

```
Email:
Subject: Re: Offer - [Your Name]

Hi [Recruiter],

Thank you again for the offer. I'm very excited about joining [Company] 
and contributing to [Project].

However, I was hoping we could discuss the compensation. Based on my 
research (Levels.fyi shows $X-$Y for this role) and my experience 
[Specific achievements], I was expecting closer to $Z.

Would it be possible to meet at $Z or structure it as:
• Base: $A
• Equity: B% (vs current C%)
• Signing bonus: $D (to bridge gap)

I'm confident I can deliver [Value proposition]. Looking forward to 
finding a solution that works for both of us!

Best,
[Name]
```

**Negotiation tips:**
- Be collaborative ("Let's find a solution")
- Give evidence (Market data, achievements)
- Multiple options (Salary, equity, bonus)
- Timeline (6-month review if can't budge now)

---

### E. Non-Salary Perks to Negotiate

If salary stuck:

- [ ] **Equity:** +5-10% shares
- [ ] **Signing bonus:** $5k-$10k one-time
- [ ] **Home office budget:** $2k for desk/monitor/chair
- [ ] **Learning budget:** $1k/year (Courses, books, conferences)
- [ ] **Coworking pass:** $200/month (If you hate home office)
- [ ] **Extra vacation:** 25 days vs 20 days
- [ ] **Title bump:** "Senior" title helps future job search
- [ ] **Early review:** 6 months vs 1 year (Faster raise)

## 9. Legal & Tax

### A. Employment Structure

**Option 1: Contractor (1099 - US) / Freelancer:**
- **Pros:** Simple, flexible
- **Cons:** No benefits, unstable
- **Tax:** Self-employed tax (~5-10% VN)

**Option 2: EOR (Employer of Record):**
- Companies use: **Remote.com, Deel, Oyster**
- **How it works:** 
  - US company pays EOR
  - EOR hires you as VN employee
  - You get salary + benefits (Health insurance)
- **Cost:** Company pays (~20% extra), not you

**Option 3: Incorporate (Set up company):**
- If earning >$50k/year
- **VN:** Hộ kinh doanh (5% tax) or Công ty (25% tax)
- **Consult accountant** (Fee: 1-2M VND/month)

---

### B. Tax Vietnam

**Income from abroad:**
- **<120M VND/year ($5k):** Unclear (Many ignore, risky)
- **>120M VND/year:** Must declare
  - Register Hộ kinh doanh: 5% tax
  - Or declare personal income: Progressive tax (5-35%)

**Recommendation:**
- Hire accountant when earning >$20k/year
- Keep records (Invoices, contracts, payment receipts)

---

### C. Receiving Payment

**PayPal:**
- Fee: 3-5%
- Limit: $25k/year personal account
- Withdraw to VN bank: 3-5 days

**Wise (TransferWise):**
- Fee: 1-2% (Cheaper than PayPal)
- Multi-currency account
- VND supported

**Payoneer:**
- Good for Toptal, Upwork
- Withdraw via ACB, VCB banks

**Cryptocurrency (Web3 jobs):**
- USDT/USDC to Binance → Sell for VND
- Fee: ~1%
