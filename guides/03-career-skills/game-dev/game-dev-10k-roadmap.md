# Kế hoạch đạt $10,000/tháng cho Game Developer (Mid-level, 3-5 năm)

Dựa trên thông tin bạn cung cấp:

*   **Level hiện tại:** Mid-level (2-4 năm kinh nghiệm)
*   **Lĩnh vực:** Game Development (Unity/Unreal)
*   **Timeline:** 3-5 năm (Bền vững)
*   **Thu nhập hiện tại (ước tính):** ~$800-$1200/tháng

Tôi đã phân tích các tài liệu trong hệ thống và thiết kế một roadmap 3 giai đoạn phù hợp với bạn:

| Con đường | Timeline | Độ khó | Phù hợp với bạn? |
| :--- | :--- | :--- | :--- |
| **1. Remote Senior Job** | 2-4 năm | ⭐⭐⭐⭐ | ✅ **HIGHLY RECOMMENDED** |

Kết hợp **Path 1 + Path 2**:

*   **Primary:** Remote Senior Game Dev Job ($6k-$8k/tháng)

## 🗓️ ROADMAP CHI TIẾT: 3-5 NĂM

### GIAI ĐOẠN 1: Năm 1-2 - Foundation & Specialization
**Mục tiêu:** Mid → Senior + Build side income | **Thu nhập target:** $2k-$4k/tháng

#### **Quý 1-2: Chọn Specialty (Bắt buộc)**
Game Dev rộng quá, bạn cần niche down để nổi bật:

Chọn **1 trong 3**:

1.  **Game Server/Multiplayer Engineer** 🔥 (Highest demand)
    *   Tech: Mirror/Netcode + Docker + AWS/GCP
    *   Salary: $80k-$120k/năm remote
    *   Tài liệu: [game-server-guide.md](../../../domains/game-dev/game-server-guide.md)

2.  **Mobile Game Optimization Expert** 📱
    *   Tech: Unity mobile, performance profiling, battery optimization
    *   Niche: Hyper-casual, mid-core games
    *   Salary: $60k-$100k/năm

3.  **Technical Artist** 🎨
    *   Tech: Shader Graph, HLSL, VFX, URP/HDRP
    *   Rare skill → High pay
    *   Salary: $80k-$130k/năm

**Action items:**
*   [ ] Chọn 1 specialty (Tuần 1)
*   [ ] Hoàn thành 1 advanced course về specialty đó (Tháng 1-2)
*   [ ] Build 1 portfolio project showcase specialty (Tháng 2-3)

#### **Quý 3-4: Improve English + Start Freelancing**
**English (IELTS 6.5 → 7.0+):**
*   Cambly 30 phút/ngày (Speaking)
*   Viết 1 technical blog/tuần (Writing)
*   Xem GDC talks không phụ đề (Listening)
*   Budget: $100-150/tháng

**Freelance (Side income $300-800/tháng):**
*   Setup Upwork + Fiverr profile
*   Bid 20-30 jobs/tháng
*   Win 2-3 small projects ($200-500)
*   Get 5-star reviews
*   Tài liệu: [game-dev-freelance-guide.md](./game-dev-freelance-guide.md)

**Kết quả Năm 1:**
*   ✅ Expert trong 1 specialty
*   ✅ English fluent (IELTS 7.0+)
*   ✅ Side income $300-800/tháng
*   ✅ Portfolio showcase specialty
*   ✅ **Total income: $2k-$3k/tháng** (VN job + freelance)

---

### GIAI ĐOẠN 2: Năm 2-3 - Go Remote & Scale
**Mục tiêu:** Land remote job + Grow freelance | **Thu nhập target:** $5k-$7k/tháng

#### **Tháng 13-18: Remote Job Hunt**
**Chuẩn bị:**
*   Polish GitHub (3-5 polished projects)
*   Create portfolio website (yourname.dev)
*   Practice LeetCode (30 Medium problems)
*   Study System Design (Multiplayer systems)
*   Create demo reel (2-3 phút video)

**Application strategy:**
*   Apply 100+ jobs trong 3-6 tháng
*   Target: US/EU startups, Web3 gaming, Remote-first studios
*   Platforms: RemoteOK, WeWorkRemotely, Hitmarker
*   Tài liệu: [remote-game-dev-guide.md](./remote-game-dev-guide.md)

**Interview prep:**
*   Unity technical questions
*   Live coding (Implement game mechanics)
*   System design (Server architecture)
*   Behavioral (STAR method)
*   **Target salary:** $60k-$80k/năm ($5k-$6.5k/tháng)

#### **Tháng 19-24: Onboarding + Freelance Growth**
**Remote job:**
*   First 90 days: Prove yourself (Ship 1-2 features)
*   Build relationships với team
*   Learn codebase & processes

**Freelance scale:**
*   Tăng rate lên $40-60/giờ
*   Focus vào repeat clients
*   Build 1 Unity Asset Store product
*   Target: $1k-$1.5k/tháng passive/active income

**Kết quả Năm 2-3:**
*   ✅ Remote Senior position ($5k-6.5k/tháng)
*   ✅ Freelance/Asset Store ($1k-1.5k/tháng)
*   ✅ **Total: $6k-$8k/tháng**

---

### GIAI ĐOẠN 3: Năm 3-5 - Optimize & Exceed $10k
**Mục tiêu:** Senior → Lead hoặc maximize freelance | **Thu nhập target:** $10k-$15k/tháng

#### **Option A: Promotion Path (Safer)**
**Tại remote company:**
*   Lead 1-2 major projects end-to-end
*   Mentor 2-3 junior developers
*   Contribute to architecture decisions
*   Build personal brand (Conference talks, blog)
*   **Target:** Promotion to Senior/Staff → $100k-$140k/năm ($8k-$12k/tháng)

**Freelance passive income:**
*   Scale Asset Store ($1k-$2k/tháng)
*   Create Unity course (Udemy) ($500-$1k/tháng)
*   Total side income: $1.5k-$3k/tháng

**Total income: $9.5k-$15k/tháng**

#### **Option B: Elite Freelance Path (Higher risk, higher reward)**
**Nếu bạn thích tự do:**
*   Quit remote job → Full-time freelance
*   Join Toptal ($80-150/giờ)
*   Work 120-150h/tháng
*   Target: $10k-$15k/tháng
*   Risk: Không ổn định, không benefits

**Kết quả Năm 3-5:**
*   ✅ $10k-$15k/tháng (Path A hoặc B)
*   ✅ Recognized expert trong specialty
*   ✅ Financial freedom
