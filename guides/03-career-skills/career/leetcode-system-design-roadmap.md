## 🧭 Lộ trình Luyện LeetCode + System Design → Apply Big Tech / High-paying Startups

> Mục tiêu: Sau 4–6 tháng đạt mức sẵn sàng phỏng vấn Senior+ tại Big Tech hoặc startup trả lương cao (US/EU). Lộ trình gồm 4 pha và checklist cụ thể.

### Phase 0 – Nền tảng & Setup (Tuần 0–2)
1. **Đánh giá hiện trạng:**
   - Làm `case-studies/knowledge-audits/dsa-knowledge-audit.md` và `domains/backend-dev/INDEX.md` để biết điểm mạnh/yếu.
   - Đánh dấu số bài LeetCode đã làm, system design đã đọc.
2. **Chuẩn bị môi trường:**
   - Account LeetCode (Premium nếu có thể), NeetCode roadmap, VisuAlgo.
   - Tài liệu system design: "System Design Interview Vol.1/2", System Design Primer.
3. **Schedule:**
   - Block tối thiểu 2h Deep Work mỗi ngày (sử dụng `templates/productivity/deep-work-scheduler.md`).
   - Weekly review (`templates/weekly-review.md`) để theo dõi tiến độ.

### Phase 1 – LeetCode Fundamentals (Tuần 3–8)
**Mục tiêu:** 75–100 bài Easy/Medium, nắm chắc patterns cốt lõi.

| Tuần | Chủ đề | Checklist |
|:-----|:-------|:----------|
| 3 | Arrays, Strings, Two Pointers | 15 bài (Two Sum, Sliding Window), note giải bằng tiếng Anh |
| 4 | HashMap, Stack/Queue | 15 bài, luyện viết giải thích 2 phương án |
| 5 | Trees, DFS/BFS | 15 bài, vs `domains/dsa/trees-graphs.md` |
| 6 | Linked List, Recursion | 15 bài, trace call stack |
| 7 | Sorting, Binary Search, Heaps | 15 bài, đo độ phức tạp |
| 8 | Dynamic Programming cơ bản | 10 bài (Climbing Stairs, House Robber, LIS) + 5 bài review lỗi |

**Thói quen:**
- Mỗi bài → ghi lại brute force, optimal, edge cases.
- 2 ngày/lần: giải 1 bài dưới áp lực thời gian 20 phút.

### Phase 2 – Advanced LeetCode + System Design (Tuần 9–16)
**Mục tiêu:** 50–75 bài Medium/Hard + 8 đề system design phổ biến.

| Tuần | LeetCode | System Design |
|:-----|:---------|:--------------|
| 9 | Graph & Union Find + Bit Manipulation | Design URL Shortener, Pastebin |
| 10 | Advanced DP (Knapsack, Interval) | Design Rate Limiter, News Feed |
| 11 | Backtracking & Math | Design Messaging system (WhatsApp) |
| 12 | Review + Mixed sets | Design Ride Sharing (Uber) |
| 13 | Hard mode (choose 10 bài) | Design Video Streaming (YouTube/Netflix) |
| 14 | SQL + Concurrency | Design E-commerce Checkout |
| 15 | Mock coding interviews (2/tuần) | Design Payment system (Stripe-like) |
| 16 | Revisit weak topics | Design scalable API Gateway |

**System Design Practice:**
- Template 4 bước: Clarify → Estimation → High-level → Deep dive (theo `domains/backend-dev/system-design-guide.md`).
- Mỗi buổi vẽ sơ đồ, viết note trade-off.

### Phase 3 – Mock Interview & Portfolio (Tuần 17–20)
1. **Mock Coding:**
   - Pramp, AlgoExpert, Interviewing.io.
   - 2 session/tuần, record lại để rút kinh nghiệm.
2. **Mock System Design:**
   - Partner trong community (Discord, Slack), theo format 45 phút.
3. **Behavioral & Storytelling:**
   - Sử dụng STAR framework, chuẩn bị 6 câu chuyện (Leadership, Conflict, Failure, Impact).
4. **Portfolio & Resume:**
   - Update CV (`templates/career/cv-template-global.md`).
   - Viết 1 bài blog technical (system design case study).

### Phase 4 – Apply Strategy (Tuần 21+)
1. **Target List:**
   - 30 công ty (Big Tech, fintech, AI infra, Series B-D startups).
   - Thông tin: liên hệ, referral potential, vị trí phù hợp.
2. **Pipeline:**
   - Mỗi tuần apply 5–7 job, track bằng Notion.
   - Ưu tiên referral (LinkedIn, alumni, mentors).
3. **Interview Loop Prep:**
   - Coding round: 2 bài Medium trong 45 phút.
   - System design: 2 đề bất kỳ, highlight trade-off.
   - Behavioral: align với leadership principles (Amazon, Meta).
4. **Recovery & Iteration:**
   - Sau mỗi vòng, ghi chú câu hỏi, lesson learned.
   - Điều chỉnh study plan (ví dụ: thiếu concurrency → bổ sung tuần chuyên sâu).

### Checklist nhanh
- [ ] Hoàn thành 150–180 bài LeetCode (75% Medium, 15% Easy, 10% Hard).
- [ ] Viết 8–10 system design case study với sơ đồ + trade-off.
- [ ] 10 mock coding + 5 mock system design + 5 behavioral rehearsal.
- [ ] Portfolio/GitHub cập nhật 2 dự án backend thể hiện scale.
- [ ] Danh sách 30 công ty + referral map.

### Tài nguyên gợi ý
- **LeetCode:** NeetCode IO roadmap, Blind 75, LeetCode Premium.
- **System Design:** System Design Primer, ByteByteGo, Alex Xu books, `domains/backend-dev/system-design-guide.md`.
- **Mock:** Pramp, Interviewing.io, LeetCode Discord.
- **Tracking:** `templates/okr-planning.md`, `templates/personal-metrics-dashboard.md`.

> *Tip:* Đối với Big Tech, consistency quan trọng hơn một cú nhảy nước rút. Mỗi tuần hoàn thành 10–12 bài LeetCode & 1 đề system design sẽ bền vững hơn việc cram 40 bài cuối tuần.
