# 🧠 IELTS Grammar Roadmap (Band 7.5+)

> Module trọng tâm giúp bứt phá từ 6.5 → 7.5+ nhờ kiểm soát cấu trúc câu, thì và tránh lỗi người Việt.

## 📚 Cấu trúc module

1. **[Tenses Masterclass](./tenses-masterclass.md):** 12 thì với mẫu câu chuẩn IELTS + bẫy phổ biến.
2. **[Complex Sentences](./complex-sentences.md):** Relative clauses, participle phrases, conditionals → nâng band coherence.
3. **[Common Errors (Vietnamese Learners)](./common-errors-vietnamese.md):** Lỗi điển hình người Việt + cách sửa nhanh.
4. **[Grammar for Band 8](./grammar-for-band-8.md):** Inversion, cleft sentence, concession structures để đạt độ “sophisticated control”.

## 🎯 Lộ trình khuyến nghị

| Tuần | Mục tiêu | Hoạt động chính |
| --- | --- | --- |
| 1 | Ôn 12 thì & timeline | Bảng tóm tắt + 12 câu mô tả biểu đồ / Speaking Part 1 |
| 2 | Complex Sentences | Viết lại Task 2 body sử dụng relative clause + conditionals dạng nâng cao |
| 3 | Sửa lỗi người Việt | Diagnostic test → flashcard lỗi cố hữu |
| 4 | Cấu trúc Band 8 | Chèn inversion/cleft vào 2 bài Task 2 + 3 cue card |
