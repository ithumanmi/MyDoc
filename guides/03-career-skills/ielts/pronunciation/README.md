# 🗣️ Pronunciation Deep Dive

> Bộ công cụ nâng điểm **Pronunciation** (Speaking) cho người học Việt Nam.

## 📁 Module Structure

1. **[IPA cho người Việt](./ipa-for-vietnamese.md)** – Bảng âm + so sánh ví dụ tiếng Việt.
2. **[Problem Sounds](./problem-sounds.md)** – /θ/, /ð/, /l/-/n/, âm cuối.
3. **[Intonation Patterns](./intonation-patterns.md)** – Rising/Falling, sentence stress.
4. **[Connected Speech](./connected-speech.md)** – Linking, elision, assimilation.
5. **[Minimal Pairs Drill](./minimal-pairs-drill.md)** – Bảng luyện ship/sheep, bad/bed...

## 🗓️ Routine Gợi ý

| Day | Focus | Action |
| --- | --- | --- |
| Mon | IPA + Problem Sounds | Shadowing 10 phút + ghi âm |
| Wed | Connected Speech | Luyện bài đọc, mark linking |
| Fri | Intonation | Đọc script Speaking Part 2 với rising/falling |
| Sun | Minimal Pairs Test | Tự quiz, cập nhật lỗi |

## 🎯 Mục tiêu

- Giảm lỗi phát âm “quốc dân” → tăng comprehensibility.
- Thêm sentence stress, intonation → Speaking Part 2/3 tự nhiên.
- Ghi âm → so sánh waveform bằng app (Audacity, Elsa).
