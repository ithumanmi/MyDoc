# 📈 Intonation & Stress Patterns

## 1. Rising vs Falling

| Pattern | Use Case | Example |
| --- | --- | --- |
| Falling ↘️ | Statements, WH-questions | "I live in Hà Nội." |
| Rising ↗️ | Yes/No question, surprise | "Do you like coffee?" |
| Fall-Rise ↘️↗️ | Contrast, uncertainty | "I *do* like it... when it's hot." |

**Drill:** Đọc 5 câu, ghi chú ký hiệu mũi tên.

## 2. Sentence Stress

- Nhấn vào content words (noun, verb, adjective).
- Function words (a, the, of) đọc nhẹ.

**Exercise:** Viết transcript Part 2 → highlight từ cần stress.

## 3. Thought Groups

- Chia câu dài thành cụm ý: "Nowadays // many cities // invest in public transport".
- Giữa các group pause 0.2s.
