# 🧠 IELTS Vocabulary Hub

> Module flashcard + topic wordlists để tăng **Lexical Resource** từ 6.0 → 8.0.

## 📦 Nội dung

1. **Anki Decks** (`./anki-decks/`)
   - `ielts-academic-core-500.apkg`: 500 từ học thuật + ví dụ Task 2.
   - `ielts-speaking-topics.apkg`: Collocation & idiom theo chủ đề cue card.
   - `ielts-writing-collocations.apkg`: Cụm động từ/danh từ nâng band 7+.
2. **Topic Wordlists** (`./topic-wordlists/`)
   - `environment-100-words.md`
   - `technology-100-words.md`
   - `education-100-words.md`
   - Mỗi file: 100 từ + định nghĩa ngắn + mẫu câu.
3. **[Collocations by Band](./collocations-by-band.md)**
   - Band 6 vs 7 vs 8: cụm từ nâng cấp cho Writing & Speaking.

## 🗂️ Cách sử dụng

| Bước | Hành động | Ghi chú |
| --- | --- | --- |
| 1 | Import deck phù hợp band hiện tại | Anki -> File -> Import |
| 2 | Chọn 1 topic wordlist/tuần | Ôn active recall + tạo câu|
| 3 | Viết 1 paragraph dùng 5 collocation mới | Dùng template PEER |
| 4 | Review cuối tuần bằng quiz tự tạo | Đảm bảo retention > 80%|
