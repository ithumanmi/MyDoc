# 📝 Practice Tests Hub

> Làm mock test đúng chuẩn Cambridge để đo tiến độ band.

## 📁 Cấu trúc module

1. **Mini Tests** (`./mini-tests/`)
   - Listening Section 1 (10 câu + audio link)
   - Reading Passage 1 (TFNG)
   - Writing Task 2 (40' challenge)
2. **Full Tests** (`./full-tests/`)
   - Mock Test 1 (4 kỹ năng)
   - Answer Keys (listening/reading/writing sample)
3. **Score Tracker** (`./score-tracker-template.md`)
   - Template bảng Excel/Notion để log điểm từng tuần.

## 🗓️ Cách sử dụng

| Tuần | Hoạt động | Ghi chú |
| --- | --- | --- |
| Mon-Wed | 1 mini test/ngày (Listening/Reading/Writing) | Tập trung điểm yếu |
| Thu | Review lỗi, ghi vào tracker | Phân loại: vocab, timing, strategy |
| Sat | Full mock test | Simulate exam conditions |
| Sun | Phân tích điểm, đặt mục tiêu tuần sau | Dùng Score Tracker |

## 🎯 Tips

- Đồng hồ đếm ngược (Task 1:20', Task 2:40', Reading 60').
- Sau mỗi mini test ghi chú: loại câu hỏi, lý do sai, từ vựng mới.
- Full test nên làm liên tục 2h45' để quen stamina.
