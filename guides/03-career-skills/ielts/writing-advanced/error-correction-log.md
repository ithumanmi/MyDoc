# 🗂️ Error Correction Log Template

> Dùng để tracking lỗi Writing và cách sửa.

## 1. Template

| Date | Task | Error Sentence | Issue Type | Correction | Note |
|------|------|----------------|------------|-----------|------|
| 13/03 | T2 (Education) | "Student can access..." | Subject-verb | "Students can access" | Plural noun |

## 2. Error Categories

- Grammar: verb tense, agreement, article.
- Lexical: word choice, collocation.
- Cohesion: linking, referencing.
- Task Response: thiếu idea, off-topic.

## 3. Workflow

1. Viết essay → highlight lỗi.
2. Ghi vào log + phân loại.
3. Viết câu mới sử dụng cấu trúc đúng.
4. 1 tuần review, xem lỗi nào lặp lại nhiều nhất.

## 4. Automation Tips

- Dùng Google Sheets/Notion → filter theo loại lỗi.
- Dùng ChatGPT/Grammarly để gợi ý correction.
