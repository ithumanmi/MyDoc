# 🔗 Coherence & Cohesion Deep Dive

## 1. Beyond Linking Words
- Dùng logical progression: General → Specific → Example → Result.
- Topic sentence rõ ràng + concluding sentence.

## 2. Cohesive Devices nâng cao

| Device | Example |
| --- | --- |
| Referencing | "This phenomenon", "Such policies" |
| Substitution | "do so", "one" |
| Ellipsis | "Developed countries invest more; developing (countries) less." |
| Parallelism | "Not only..., but also..." |

## 3. Paragraph Flow Checklist

- [ ] Topic sentence → preview idea.
- [ ] Supporting detail 1 + evidence.
- [ ] Supporting detail 2 + mini conclusion.
- [ ] Linking phrases tự nhiên (không lạm dụng Firstly/Secondly).

## 4. Practice Exercise

- Chọn bài mẫu Band 9 → phân tích cohesive devices.
- Viết lại đoạn văn, thay thế >50% linking words bằng referencing/parallelism.
