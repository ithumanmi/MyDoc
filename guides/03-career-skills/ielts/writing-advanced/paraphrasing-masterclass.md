# 🔁 Paraphrasing Masterclass

## 1. Vì sao quan trọng?
- Tránh lặp từ trong Intro/Body → tăng LR.
- Giữ ý gốc nhưng thay đổi cấu trúc.

## 2. Công cụ paraphrase

| Technique | Example |
| --- | --- |
| Synonym swap | "big problem" → "significant issue" |
| Structural change | "Because X, Y" → "Y happens due to X" |
| Nominalization | "Countries invest" → "Investment by countries" |
| Clause reduction | "who are living" → "living" |

## 3. Template Intro

- Topic statement: dùng synonyms.
- Thesis: paraphrase câu hỏi + ý chính.

**Ví dụ:**
- Question: "Some people think cars should be banned in city centres."
- Paraphrase: "It is argued that private vehicles ought to be prohibited from urban cores."

## 4. Body Paraphrasing

- Dùng "referencing": this trend, such initiatives.
- Dùng collocation đa dạng: "tackle congestion", "alleviate bottlenecks".
