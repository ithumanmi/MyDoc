# 🧾 Academic Style Guide

## 1. Tone

- Tránh contractions: "don't" → "do not".
- Dùng formal verbs: "kids" → "children", "get" → "obtain".

## 2. Sentence Structure

- Ưu tiên complex/compound sentences nhưng phải rõ nghĩa.
- Dùng passive khi cần neutral tone: "It is widely believed...".

## 3. Register Checklist

- [ ] Không dùng slang/idiom quá casual ("cool", "awesome").
- [ ] Tránh câu hỏi tu từ không cần thiết.
- [ ] Sử dụng hedging: "It seems that", "This suggests".

## 4. Vocabulary Upgrade

| Informal | Academic |
| --- | --- |
| kids | children / youngsters |
| a lot of | a considerable number of |
| get better | improve / enhance |
| rich | affluent / wealthy |

## 5. Practice

- Rewrite 1 essay → highlight từ informal và thay thế.
- Nhờ partner review tone consistency.
