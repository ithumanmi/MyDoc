# 🛠️ Technical Skills for MMO: Công cụ của Chiến binh

> [← Back to MMO Roadmap](../README.md)

Bạn không cần phải là Hacker, nhưng bạn phải biết dùng công cụ.

---

## 1. Web Development Cơ bản (Base)

Dù làm mảng nào, bạn cũng cần một "căn cứ địa" (Website/Landing Page).
*   **CMS (WordPress):**
    *   Cài đặt Hosting (Cpanel, DirectAdmin).
    *   Trỏ Domain (DNS Record: A, CNAME).
    *   Theme & Plugin cơ bản (Yoast SEO, RankMath, Elementor).
*   **Landing Page (Ladipage/Instapage):**
    *   Tạo trang bán hàng nhanh (Sales Page).
    *   Kết nối Google Sheet để hứng Lead.
*   **HTML/CSS cơ bản:** Để chỉnh sửa màu sắc, font chữ khi cần thiết.

---

## 2. Automation Tools (Tự động hóa)

Làm MMO mà làm tay (Manual) thì chỉ kiếm tiền lẻ. Hãy dùng Tool.

> **Xem thêm:** [MMO Automation Tools](../../domains/network-security/mmo-engineering/automation-tools.md)

*   **Browser Automation:** Selenium, Puppeteer (NodeJS), Python.
*   **Macro Recorder:** AutoIt, Macro Scheduler (Cho người không biết code).
*   **No-Code Tools:** Zapier, IFTTT (Kết nối các ứng dụng với nhau).
    *   Ví dụ: Khách điền Form -> Tự động gửi Email -> Tự động thêm vào Google Sheet -> Tự động báo về Telegram.

## 3. AI Content Creation (Vũ khí mới)

*   **ChatGPT / Claude:**
    *   Viết kịch bản Video (Script).
    *   Viết bài chuẩn SEO (Blog Post).

*   **Midjourney / Stable Diffusion:**

*   **Video AI:**
    *   HeyGen / D-ID: Tạo MC ảo nói chuyện.

## 4. VPS & Network (Hạ tầng)

Khi bạn muốn chạy 100 nick Facebook cùng lúc, máy tính cá nhân sẽ nổ tung.

> **Xem thêm:** [Proxy Infrastructure](../../domains/network-security/mmo-engineering/proxy-infrastructure.md)

*   **VPS (Virtual Private Server):** Thuê máy tính ảo trên Cloud (Google Cloud, Azure, Vultr) để treo Tool 24/24.
*   **Proxy / 4G:** Fake IP để mỗi nick một IP khác nhau, tránh bị khóa.
*   **Antidetect Browser:** Giả lập vân tay trình duyệt (Gologin, Multilogin).

*   Tìm tài liệu (Filetype:pdf, site:drive.google.com).
