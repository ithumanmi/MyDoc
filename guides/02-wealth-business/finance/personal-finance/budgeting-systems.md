# 💸 Budgeting Systems Playbook

> "Every dollar needs a job." – Rule #1

## 1. Các framework phổ biến

### 1.1 50/30/20
- **50% Needs:** nhà ở, ăn uống, transport, bảo hiểm bắt buộc.
- **30% Wants:** du lịch, giải trí, hobby.
- **20% Savings/Investing:** quỹ khẩn cấp, đầu tư ETF, hưu trí.
> Dành cho người mới, thu nhập ổn định.

### 1.2 Zero-Based Budget (ZBB)
- Thu nhập – chi tiêu = 0 (tất cả dòng tiền có mục đích).
- Phù hợp người thu nhập biến động (freelancer) hoặc muốn tối ưu từng đồng.
- Tools: YNAB, Money Lover, Notion template tự build.

### 1.3 Envelope / Bucket System
- Chia thành các "phong bì" vật lý hoặc digital (ứng dụng ngân hàng đa tài khoản).
- Hữu ích khi kiểm soát cash, tránh overspend.

## 2. Thiết lập hệ thống

1. **Map dòng tiền:** liệt kê nguồn thu (salary, side gig) và lịch thanh toán cố định.
2. **Chọn framework:** có thể kết hợp (50/30/20 + envelope cho Wants).
3. **Công cụ:**
    - Spreadsheet: Google Sheet có pivot, conditional formatting.
    - App: YNAB, Spendee, Timo Goal Save (VN ngân hàng).
4. **Automation:** bank rule chuyển tiền vào tài khoản con ngay khi nhận lương.

## 3. Dashboards & Review

| Cadence | Mục tiêu | Hành động |
| --- | --- | --- |
| Weekly | Theo dõi cash-on-hand | Đồng bộ giao dịch, cập nhật categories |
| Monthly | Budget vs Actual | Điều chỉnh subscription, đàm phán chi phí |
| Quarterly | Rebalance allocation | Update target % theo mục tiêu mới |

## 4. Template tham khảo
- Google Sheet Budget Tracker (bao gồm sheet Needs/Wants/Savings).
- Notion Budget OS (link database transaction + goal).
- Script Python (Pandas) để import file CSV ngân hàng, auto categorize.

## 5. Tips thực tế VN
- Dùng tài khoản phụ trong Vietcombank, Techcombank, Timo để chia envelope digital.
- Ghi nhận chi tiêu tiền mặt bằng QR/ảnh hoá đơn → sync hàng ngày.
- Giao dịch QR/không tiền mặt → dễ import và phân loại.
