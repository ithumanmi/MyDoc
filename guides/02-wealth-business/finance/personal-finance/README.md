# 🧭 Personal Finance Module

> "Tiền là công cụ, không phải mục tiêu." – Operating principle

Module cung cấp hệ thống quản lý tài chính cá nhân từ nền tảng (budgeting, quỹ khẩn cấp) đến tối ưu thuế và nghỉ hưu tại Việt Nam. Các playbook được thiết kế để bạn áp dụng ngay với template, checklist và công cụ số.

---

| File | Mục tiêu |

| [emergency-fund-strategy.md](./emergency-fund-strategy.md) | Xây quỹ khẩn cấp 3-6-12 tháng, liquidity ladder. |

> Khuyến nghị đọc tuần tự: Budgeting → Emergency Fund → Debt → Insurance → Retirement → Tax → Net worth tracking.

---

## Operating Principles

1. **Automate first:** mọi dòng tiền quan trọng phải tự động.
2. **Separate buckets:** tài khoản riêng cho quỹ khẩn cấp, đầu tư, chi tiêu.
3. **Review cadence cố định:** weekly cashflow, monthly budget, quarterly net worth.
4. **Localization:** mỗi playbook có section dành riêng cho Việt Nam (BHXH, PIT, ngân hàng nội địa).

---

## Quick Start Checklist

- [ ] Hoàn thành `budgeting-systems.md` → chọn framework phù hợp.
- [ ] Tạo quỹ khẩn cấp ≥ 3 tháng trong 60 ngày.
- [ ] Map toàn bộ khoản nợ + lộ trình trả (avalanche/snowball).
- [ ] Kiểm tra bảo hiểm hiện có, bổ sung shortfall.
- [ ] Tính retirement number & timeline (VN).
- [ ] Set up net worth dashboard + alert.
