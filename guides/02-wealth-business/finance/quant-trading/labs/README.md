# Quant Trading Labs (Hands-on)

Notebook samples để chạy nhanh:

1) `backtest-moving-average.ipynb` — crossover SMA 20/50, metrics cơ bản.
2) `pairs-trading-cointegration.ipynb` — kiểm tra cointegration, trade spread XOM/CVX.
3) `factor-model-construction.ipynb` — tính factor size/value/momentum từ yfinance.
4) `ml-feature-engineering.ipynb` — tạo feature (returns, vol, RSI) + LightGBM classifier.
5) `execution-simulation.ipynb` — mô phỏng bid-ask, slippage đơn giản.
6) `risk-metrics-calculation.ipynb` — VaR, CVaR, Sharpe, Sortino, MaxDD.

> Yêu cầu: Python 3 + `pip install -U yfinance statsmodels lightgbm scikit-learn pandas numpy`.
