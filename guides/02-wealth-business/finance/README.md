## 5. Cách sử dụng module
1. **Xác định nhu cầu:** macro insight, domain project hay quant trading.
2. **Chọn playbook:** dùng bảng trên để nhảy vào file phù hợp.
3. **Kết nối cross-module:** khi làm product banking, xem thêm legal/compliance và investing.
4. **Đóng góp:** nếu bạn có case study, mở PR để bổ sung.
