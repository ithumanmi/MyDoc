# Gaming as leisure

> [← Play](./README.md) · [Fun-maxing](../../04-lifestyle-os/life-os/fun-maxing.md) · [High-quality leisure](../../04-lifestyle-os/well-being/mental-resilience/high-quality-leisure.md)

**Agent SUMMARY**
- Game = leisure tool: deep fun khi có start/stop + skill/curiosity; cheap khi queue vô hạn / FOMO.
- Protocol: mục tiêu session → time box → stop rule → 1 dòng afterglow.
- Fun budget tuần; tách Play vs Make research vs Follow scroll.
- Educational — không chẩn đoán nghiện game; distress kéo dài → chuyên gia.

## 1. Hai chế độ chơi

| | **Deep play** | **Doomscroll gaming** |
| --- | --- | --- |
| Cấu trúc | Session chọn trước, kết thúc rõ | Queue / FOMO / “one more” vô hạn |
| Năng lượng sau | OK hoặc + (muốn kể / nhớ) | Fog, tiếc thời gian, khó ngủ |
| Dopamine | Muốn lại vì *liking* | Chase *wanting* — spike rồi trống |
| Vai trò Leisure OS | Active leisure / deep fun | Cheap fun — nếu có thì **cap** |

Chi tiết cheap vs deep: [`fun-maxing.md`](../../04-lifestyle-os/life-os/fun-maxing.md).  
Passive vs active leisure: [`high-quality-leisure.md`](../../04-lifestyle-os/well-being/mental-resilience/high-quality-leisure.md).

**Lưu ý:** game online cạnh tranh / grind vẫn có thể deep nếu bạn *chọn* khung (ranked set, co-op night). Không phải genre quyết định — **thiết kế session** quyết định.

## 2. Session protocol (5′ trước / trong / sau)

### Trước

1. **Mục tiêu 1 câu:** clear chapter · learn matchup · chill co-op · art/story only.
2. **Time box:** gắn giờ hoặc “hết quest X”.
3. **Mood match:** xem [genre-taste-map](./genre-taste-map.md) — stress ≠ luôn mở ranked.

### Trong

- Một title chính; tránh alt-tab feed / store wishlist.
- Nếu tilt hoặc “auto-queue”: **pause 2 phút** — quyết định tiếp hay stop (không mặc định tiếp).

### Sau (≤1 phút)

Ghi 1 dòng: `game | phút | vibe (−/0/+) | deep hoặc cheap`.  
Optional → `personal/` nếu muốn track dài hạn.

## 3. Fun budget (game)

Gắn vào fun budget tổng ([fun-maxing §7](../../04-lifestyle-os/life-os/fun-maxing.md)):

| Khay | Ví dụ trong game | Rule |
| --- | --- | --- |
| **Deep** | Skill game, story-heavy, co-op có hẹn | Block trên lịch tuần |
| **Cheap** | Idle tap, gacha spam, clip-chase, infinite queue | Timer cứng (vd. ≤20′/ngày) |
| **Relational** | Party game / voice với inner circle | ≥1 block/tuần nếu social là mục tiêu |
| **Restorative** | Không screen — đi bộ, analog | Game **không** thay slot này |

Gợi ý khởi điểm: Deep game ≥ 2–3 block ngắn/tuần · Cheap có timer · không mượn giờ ngủ.

## 4. Stop rules (chọn 2–3)

- Hết time box / quest đã khai.
- Hai thua liên tiếp + tilt lên.
- Đồng hồ sinh học: cắt trước cửa sổ ngủ (xem [dopamine / sleep](../../04-lifestyle-os/health/dopamine-system.md) + sleep protocol).
- “Chơi vì trống việc” → đổi sang restorative 10′ trước khi mở game.

## 5. Khi play nuôi Make / Earn

| Tình huống | Xử lý |
| --- | --- |
| Research genre cho project | Đánh dấu session **Make-research** — ghi 3 bullet design, không tính pure leisure nếu chiếm deep-work block |
| Xem stream “học” mãi không ship | Đó là Follow/cheap — chuyển [Follow hub](../follow/README.md) time-box |
| Play để tránh ship | Stop rule + 25′ Make trước khi được Play |

## 6. Checklist nhanh

**Trước session**

- [ ] Mục tiêu 1 câu + time box
- [ ] Mood ↔ genre ok
- [ ] Không nợ ngủ lớn

**Sau session**

- [ ] 1 dòng log
- [ ] Deep hay cheap?
- [ ] Tuân budget tuần?
