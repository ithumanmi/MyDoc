## 3. Mood → genre routing

| Mood / năng lượng | Mở | Tránh |
| --- | --- | --- |
| Căng / ít bandwidth | Cozy, story-light, short session | Ranked grind, rogue dài |
| Muốn skill / flow | Competitive / precision / puzzle hard | Idle + second screen |
| Social | Party, co-op hẹn trước | Solo binge cô lập nếu đang cần social rest |
| Creative empty (sau Make) | Narrative / awe / wander | “Research competitor” trá hình |

## 4. Profile mẫu (xóa / thay)

```text
Home: Immersive sim · Tactics · Co-op extraction (có hẹn)
Anti: Infinite live-service daily · Horror jump-scare trước ngủ
Mood stress → short story / roguelite 1 run
Mood sharp → ranked set 3 games rồi stop
```

## 5. Review quý (15′)

1. Home genre nào thật sự chơi ≥3 session?
2. Anti nào vẫn lọt vào backlog?
3. Có genre mới xứng lên home không?
