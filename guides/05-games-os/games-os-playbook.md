# Games OS Playbook

> [← Games OS](./README.md) · [Map](./games-os-map.md)

Checklist vận hành tuần — chọn **1–2 nhánh ưu tiên**, không cố max cả bốn.

## Weekly levers

| Nhánh | Thời lượng gợi ý | Việc tối thiểu |
| --- | --- | --- |
| **Make** | block deep work | 1 ship-able increment (lab / feature / design note) trong `domains/game-dev` hoặc challenge |
| **Play** | fun budget cố định | 1 session chơi có chủ đích + không vượt budget ([play/](./play/README.md)) |
| **Earn** | 1–2h | 1 career action (portfolio, pitch, apply, pricing) — career hub |
| **Follow** | ≤30–45 phút | 1 [weekly brief](./follow/weekly-games-brief-template.md) (play-culture + industry) |

## Daily (nhẹ)

- [ ] Nếu chơi: ghi 1 dòng session (game / phút / vibe) — optional `personal/`
- [ ] Nếu make: 1 commit / 1 design bullet trước khi mở feed

## Anti-patterns

| Tránh | Thay bằng |
| --- | --- |
| Scroll patch note cả tối, zero ship | Follow = brief có cấu trúc, time-box |
| Earn confusion khi đang học Unity | Tách ngày Make vs Earn |
| Play vô hạn “rest” | Fun budget + [fun-maxing](../04-lifestyle-os/life-os/fun-maxing.md) |
| Nhét tin vào domain tech | Giữ Follow trong `05-games-os/follow/` |

## Review (cuối tuần)

1. Nhánh nào thắng tuần này?
2. 1 insight Follow → có đụng Make hoặc Earn không? (đa số: không — OK)
3. Play có vượt budget không?
