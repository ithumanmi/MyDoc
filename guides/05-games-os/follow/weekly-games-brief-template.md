# Weekly games brief — template

> [← Follow](./README.md) · [Playbook](../games-os-playbook.md)

Copy block dưới vào note tuần (hoặc `personal/` nếu muốn private log).

```markdown
# Games brief — week of YYYY-MM-DD

## Play-culture (≤3 bullets)
- …
- …
- …

## Industry / biz (≤3 bullets)
- …
- …
- …

## Tags
- [ ] play-only
- [ ] earn-signal → next action: …
- [ ] make-research → next action: …

## Sources
- …

## Time spent
- __ minutes (cap 45)
```

## Tips

- Nếu không có earn/make signal: để trống — Brief vẫn hợp lệ.
- Một tuần chỉ cần **một** insight đáng nhớ, không cần cover cả ngành.
