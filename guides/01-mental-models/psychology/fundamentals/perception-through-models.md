# Perception Through Models — não không nhìn thế giới “trực tiếp”

> [← Psychology](../README.md) · [Cognition](./cognition.md) · [Predictive Processing](./predictive-processing.md) · [Cognitive Biases](../cognitive-biases.md) · [Meta-thinking](../../../03-career-skills/productivity/meta-skills/meta-thinking.md)

**Luận điểm trung tâm (tâm lý nhận thức + hành vi):** con người **không** tiếp xúc thế giới như camera trung thực. Não nhìn qua **mô hình đã có sẵn** — schema, kỳ vọng, kinh nghiệm, văn hóa, mục tiêu — rồi **điền / lọc / bóp méo** cảm giác để khớp mô hình đó đủ nhanh để hành động.

```text
Thế giới (dữ liệu thô)
        │
        ▼
   [ Mô hình sẵn có ]  ←── kỳ vọng, bias, cảm xúc, bản sắc
        │
        ▼
   "Thực tại chủ quan"  →  cảm xúc → hành vi
```

Educational. Đơn giản hóa khoa học nhận thức; không thay trị liệu khi hallucination / loạn thần.

## Agent SUMMARY

- Nhìn = **top-down** (model dẫn) + **bottom-up** (data cảm giác); model thường thắng khi mơ hồ / vội / mệt.
- Schema / mental model = bản đồ rút gọn; nhanh nhưng dễ confirmation & availability.
- Hệ quả hành vi: cùng sự kiện → khác cảm xúc/hành động vì khác model (CBT: Belief giữa A và C).
- Cập nhật model: evidence trái chiều · Meta-Filter · Feynman gap · mental models tốt thay xấu.
- Nối: [`cognition.md`](./cognition.md) · [`predictive-processing.md`](./predictive-processing.md) · [`cognitive-biases.md`](../cognitive-biases.md) · [`meta-thinking-bias-filter.md`](../../../03-career-skills/productivity/meta-skills/meta-thinking-bias-filter.md) · [`cbt.md`](../schools-of-thought/cbt.md).

## 1. Vì sao não “nhìn qua model”?

| Lý do | Ý |
| --- | --- |
| **Băng thông** | Cảm giác quá tải; não lọc ~hầu hết, chỉ giữ tín hiệu khớp mục tiêu / đe dọa / lạ ([`cognition.md`](./cognition.md) § Attention) |
| **Tốc độ** | System 1 dùng mẫu sẵn để quyết trong ms — sống sót hơn phân tích từng pixel ([System 1/2](../key-concepts.md)) |
| **Dự đoán** | Não “đoán trước” rồi chỉnh bằng lỗi dự đoán (predictive / expectation-driven sensing) — không đợi data đầy đủ. Deep: [`predictive-processing.md`](./predictive-processing.md) |
| **Tiết kiệm** | Model tốt = ít năng lượng; model cũ cứng = thiên kiến |

**Ẩn dụ:** bạn không nhìn bản đồ thế giới 1:1 — bạn nhìn **bản đồ đã vẽ sẵn** trong đầu, rồi tin đó là đường thật.

---

## 2. Các tầng “mô hình sẵn”

| Tầng | Ví dụ | Hậu quả |
| --- | --- | --- |
| **Cảm giác–nhận thức** | Ảo ảnh quang học, điền chữ bị thiếu vẫn đọc được | Data mơ hồ bị model “vá” |
| **Schema / stereotype** | “Họp kiểu này = lãng phí”; “người này = không tin được” | Selective attention |
| **Niềm tin / narrative** | “Mình phải hoàn hảo”; “thị trường luôn…” | CBT Belief → Consequence |
| **Mental models công cụ** | First principles, second-order effects | Quyết định tốt hơn *nếu* model khớp domain ([Mental Models hub](../../README.md)) |
| **Trạng thái** | Giận / mệt / FOMO | Cùng data → tô màu khác (affect heuristic) |

Gần: trí nhớ **tái tạo** không ghi camera ([`cognition.md`](./cognition.md) § Memory) — mỗi lần nhớ là model ghi đè.

## 3. Từ model → hành vi (vì sao gọi “hành vi”)

Behaviorism cổ điển nhấn S → R (kích thích → phản ứng) quan sát được ([`behaviorism.md`](../schools-of-thought/behaviorism.md)).  
Tầng nhận thức thêm:

```text
Stimulus  →  [Model / Belief]  →  Emotion / Appraisal  →  Response
```

Cùng một mail “cần nói chuyện”:
- Model A: *phê bình* → sợ → phòng thủ.  
- Model B: *cơ hội feedback* → tò mò → chuẩn bị câu hỏi.

**CBT** formal hóa: đổi B (belief/model) để đổi C ([`cbt.md`](../schools-of-thought/cbt.md)).  
**Thiên kiến** = model đang bảo vệ chính nó (confirmation, anchoring…) ([`cognitive-biases.md`](../cognitive-biases.md)).

---

## 4. Hệ quả thực dụng

1. **Tranh luận “sự thật”** thường là tranh **hai model** — trước hết làm rõ giả định.  
2. **Marketing / đàm phán / tin giả** thắng khi **hijack model** (neo, framing, scarcity).  
3. **Học** = xây & sửa model, không chỉ nhét facts — Feynman lộ chỗ model thủng.  
4. **Resilience / OI** = không gắn self-worth vào một model “phải được chọn / phải chốt” ([`outcome-independence.md`](../../../04-lifestyle-os/life-os/outcome-independence.md)).  
5. **Meta-thinking** = tầng nhìn *cái model đang chạy* chứ không chỉ nhìn vấn đề ngoài ([`meta-thinking.md`](../../../03-career-skills/productivity/meta-skills/meta-thinking.md)).

## 5. Cách làm việc *với* (không chống) bộ máy này

Não **không thể** tắt model. Mục tiêu = **biết model nào đang on** và **cập nhật khi sai**.

| Động tác | Cách |
| --- | --- |
| **Đặt tên model** | *“Mình đang dùng story gì về tình huống này?”* |
| **Tách data / diễn dịch** | 1 dòng fact thuần · 1 dòng nhãn (CBT A vs B) |
| **Tìm evidence phản** | Câu Confirmation trong Meta-Filter |
| **Đổi góc (SWITCH)** | Inversion: *nếu ngược lại vẫn hợp lý thì sao?* |
| **Cập nhật có chủ đích** | Sau fail: “Model nào sai? Thay assumption nào?” — thinking journal |
| **Nạp model tốt** | Thư viện mental models + deliberate practice domain thật |

SOP nhanh: [`meta-thinking-bias-filter.md`](../../../03-career-skills/productivity/meta-skills/meta-thinking-bias-filter.md) (STOP–ZOOM–SWITCH).  
Hệ ritual: [`metacognitive-operating-system.md`](../../metacognitive-operating-system.md).

### Micro-drill 2 phút

1. Chọn 1 phán xét mạnh hôm nay.  
2. Viết: *Model đang chạy:* …  
3. Viết: *1 data sẽ làm model này sai:* …  
4. Hỏi: hành vi của mình sẽ đổi thế nào nếu tin model kia?
