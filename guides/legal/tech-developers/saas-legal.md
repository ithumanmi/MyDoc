## 1. TERMS OF SERVICE (ToS)

### **1.1. ToS là gì?**

**Hợp đồng** giữa bạn (Service Provider) và user:
- Quy định cách user được dùng service
- Giới hạn trách nhiệm của bạn
- Quyền sở hữu IP
- Termination, refund policy

### **1.2. Cấu trúc ToS**

```
1. Acceptance of Terms
2. Description of Service
3. User Accounts & Registration
4. User Responsibilities
5. Prohibited Uses
6. Intellectual Property
7. Payment & Billing
8. Refund Policy
9. Service Modifications & Termination
10. Limitation of Liability
11. Indemnification
12. Governing Law
13. Changes to Terms
14. Contact Information
```

## 2. PRIVACY POLICY

### **2.1. Privacy Policy là gì?**

Giải thích **cách bạn thu thập, sử dụng, và bảo vệ** dữ liệu user:
- Data nào được thu thập
- Mục đích sử dụng
- Ai có quyền truy cập
- Cách bảo vệ data
- Quyền của user (Delete, export data)

### **2.2. Cấu trúc Privacy Policy**

```
1. Information We Collect

3. How We Share Your Information
4. Data Security
5. Data Retention
6. Your Rights (GDPR/CCPA)
7. Cookies & Tracking

```

## 3. GDPR COMPLIANCE

### **3.1. GDPR là gì?**

**General Data Protection Regulation** - Luật bảo vệ dữ liệu EU

⚠️ **Áp dụng nếu:**
- Có user từ EU/EEA
- Xử lý data của EU citizens

### **3.2. GDPR Requirements**

✅ **Phải có:**

**1. Lawful Basis for Processing:**
- Consent (User đồng ý)
- Contract (Cần để fulfill service)
- Legitimate Interest

**2. User Rights:**
- Access, Rectify, Delete, Export data
- Right to be forgotten

**3. Data Protection:**
- Encryption, access controls
- Data breach notification (72 hours)

**4. Privacy by Design:**
- Default privacy settings
- Minimize data collection

**5. DPO (Data Protection Officer):**
- Nếu xử lý data quy mô lớn

### **3.3. Implementation**

**Technical:**
```javascript
// Example: Delete user data (GDPR compliance)
async function deleteUserData(userId) {
  // Delete from database
  await db.users.delete({ id: userId });
  await db.userProfiles.delete({ userId });
  
  // Delete from third-party services
  await stripe.customers.del(stripeCustomerId);
  await analytics.deleteUser(userId);
  
  // Anonymize in logs
  await anonymizeUserInLogs(userId);
}

// Example: Export user data
async function exportUserData(userId) {
  const user = await db.users.findOne({ id: userId });
  const profile = await db.userProfiles.findOne({ userId });
  const usage = await db.usageLogs.find({ userId });
  
  return {
    personal: user,
    profile: profile,
    usage: usage
  }; // Return as JSON
}
```

**UI:**
```
Settings → Privacy
- [ ] Export My Data (Download JSON)
- [ ] Delete My Account (Permanent, 90-day grace period)
```

## 5. DATA PROCESSING AGREEMENT (DPA)

### **5.1. Khi nào cần DPA?**

✅ **B2B SaaS:**
- Enterprise clients (Họ là Data Controller, bạn là Data Processor)
- Client có GDPR obligations

### **5.2. DPA Template (Short)**

```markdown
# DATA PROCESSING AGREEMENT

**Between:**
- **Data Controller:** [Client Company]
- **Data Processor:** [Your SaaS Company]

## 1. PROCESSING DETAILS

**Data Types:** [Personal data of Client's customers]
**Purpose:** [Provide SaaS service]
**Duration:** [Term of subscription]

## 2. PROCESSOR OBLIGATIONS

Processor agrees to:
- Process data only as instructed by Controller
- Implement appropriate security measures
- Assist with data subject requests (Access, Delete, etc.)
- Notify Controller of data breaches within 24 hours

## 3. SUB-PROCESSORS

Processor may use:
- AWS (Hosting)
- Stripe (Payment)
- [List all sub-processors]

## 4. DATA LOCATION

Data stored in: [EU / US / Asia-Pacific]

## 5. TERMINATION

Upon termination, Processor will delete or return all data.

---

**Signatures:** [Both parties]
```

## 8. RED FLAGS - Legal Risks

🚩 **Tránh:**

- ❌ No ToS/Privacy Policy (Illegal in many jurisdictions)
- ❌ "We can change terms anytime without notice"
- ❌ Selling user data without consent
- ❌ No data encryption
- ❌ Storing passwords in plaintext
- ❌ No GDPR compliance (If có user EU)
- ❌ No refund policy (Gây trust issues)

## 9. STARTUP-FRIENDLY APPROACH

### **MVP Stage (Pre-revenue):**

**Minimum:**
- ✅ ToS (Generated từ template)
- ✅ Privacy Policy (Basic)
- ✅ HTTPS
- ⚠️ GDPR: Basic compliance (Delete user on request)

**Tools:**
- Termsfeed (Free)
- GitHub template

### **Growth Stage (Has revenue):**

**Upgrade:**
- ✅ Custom ToS/Privacy (Lawyer review: $500-2k)
- ✅ Full GDPR compliance
- ✅ DPA for enterprise clients
- ✅ Cookie consent

### **Scale Stage (Enterprise clients):**

**Full compliance:**
- ✅ Legal team review
- ✅ SOC 2, ISO 27001 (Security certifications)
- ✅ Custom DPA per client
- ✅ Insurance (Cyber liability)
