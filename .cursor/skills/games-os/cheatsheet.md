# Cheatsheet — Games OS

## Intent → branch (decide in one line)

| If user means… | Do |
| --- | --- |
| Build / design / implement | **Make** → `domains/game-dev/` |
| Money / career / publisher | **Earn** → career `game-dev/` |
| Play without burnout | **Play** → `05-games-os/play/` |
| News this week | **Follow** → `05-games-os/follow/` |
| Everything games | Hub README → map |

## Weekly defaults

| Branch | Cap | Done-when |
| --- | --- | --- |
| Make | deep block | 1 ship-able increment |
| Play | fun budget | 1 intentional session |
| Earn | 1–2h | 1 career action |
| Follow | ≤45′ | 1 brief (≤3+≤3 bullets) |

Pick **1–2** branches/week.

## Session go / no-go

| Signal | Action |
| --- | --- |
| No goal / no time box | Don’t start — set them |
| Tilt after 2 losses | Pause 2′; prefer stop |
| Near sleep window | Stop; no “one more” |
| Playing to avoid ship | 25′ Make first |
| Research for project | Tag Make-research |

## Backlog decisions

| Event | State |
| --- | --- |
| Sale / hype / gift | Later (or skip) |
| Want to commit | Need Next slot (≤3) |
| Abandoned mid | Dropped |
| Review: Next >3 | Cut to 3 |
| FOMO-only Next | Demote to Later |

## Brief tags (judgment)

| Tag | Means | Next step |
| --- | --- | --- |
| `play-only` | Awareness | None |
| `earn-signal` | Touches $ / store / hire | One Earn/market action |
| `make-research` | Touches design/build | One Make note |

**Default:** `action? none`. Prefer one memorable insight over full coverage.

## Hard no

- Play/news files inside `domains/game-dev`
- Personal metrics without user ask
- Diagnosing “game addiction” clinically from this skill
