# Patterns — Games OS

## Four-Branch Router
**When to use**: Any game-related question in Docs  
**How**: Classify Make/Play/Earn/Follow → open that hub → cite path  
**Trade-offs**: Slightly more upfront routing; avoids wrong-corpus answers

## Health-OS-Style Hub
**When to use**: Organizing a lifestyle/knowledge umbrella  
**How**: README + map + playbook + system docs; pointers for heavy curricula  
**Trade-offs**: Requires discipline not to duplicate domains/

## Session Protocol
**When to use**: Starting a play session  
**How**: Goal → time box → mood match → single title → afterglow log  
**Trade-offs**: 5′ overhead; prevents hour-long drift

## Fun Budget Khay
**When to use**: Weekly leisure planning  
**How**: Schedule Deep; timer Cheap; protect Restorative non-screen  
**Trade-offs**: Feels restrictive short-term; preserves energy long-term

## Finite Backlog
**When to use**: Wishlist / library guilt  
**How**: Caps on Playing/Next; sale→Later; monthly cut Later  
**Trade-offs**: Must drop titles deliberately

## Dual Radar + Tagged Brief
**When to use**: Staying informed without doomscrolling industry Twitter  
**How**: Culture bucket + industry bucket; weekly template; default no action  
**Trade-offs**: Incomplete coverage by design

## Make-Research Firewall
**When to use**: “Playing for research” bleeds into leisure time  
**How**: Tag session; write 3 design bullets; don’t consume leisure Next slots  
**Trade-offs**: Requires honesty about motive
