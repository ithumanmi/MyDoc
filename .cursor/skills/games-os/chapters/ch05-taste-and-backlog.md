# Chapter 5: Taste & backlog

## Core Idea
Separate **play taste** (what you enjoy) from **genre design pillars** (how you ship); keep backlog finite so Next means commitment.

## Frameworks Introduced
- **Home Genres (3–5)**: Titles you return to without FOMO
  - When to use: Choosing Next; filtering sales
  - How: Fill table; prefer home for Next
- **Anti-preferences**: Filters for post-session fatigue (not “bad games”)
- **Mood → Genre Routing**: Energy state chooses open/avoid set
- **Finite Backlog Protocol**: Playing / Next / Later / Dropped with caps and add rules

## Key Concepts
- **Wishlist ≠ backlog**: Catalog vs commitment (Next)
- **Cap**: Playing 1–2; Next ≤3
- **Add rule**: Sale→Later; promote to Next only with free slot or demotion
- **Quarterly taste review**: Which home genres got ≥3 sessions?

## Mental Models
- Use Dropped without guilt — play ≠ collecting.
- Prefer Make-research tagged separately from leisure Next.

## Anti-patterns
- **Buy on sale → auto Next**: Later only
- **15 “currently playing”**: Force 1–2 Playing
- **Guilt pile**: Drop is valid
- **Make research filling all Next**: Separate tag/slots

## Reference Tables
| Mood | Open | Avoid |
| --- | --- | --- |
| Stressed | Cozy, short, story-light | Ranked grind, long rogue |
| Sharp / skill | Competitive, precision, hard puzzle | Idle + second screen |
| Social | Party, scheduled co-op | Isolating solo binge if need social rest |
| Post-Make empty | Narrative / awe / wander | Fake “competitor research” |

| State | Cap |
| --- | --- |
| Playing | 1–2 |
| Next | ≤3 |
| Later | Soft; cut on review |
| Dropped | Unlimited honesty |

## Worked Example
Profile: Home = immersive sim, tactics, scheduled co-op extraction. Anti = mandatory dailies. Sale AAA battle-pass title → Later. Promote only if Next has slot and mood match.

## Key Takeaways
1. Taste map is leisure-facing; design pillars are Make-facing.
2. Next is scarce; protect it.
3. Monthly 10′ review prevents FOMO accretion.
