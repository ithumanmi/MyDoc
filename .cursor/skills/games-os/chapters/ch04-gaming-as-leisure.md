# Chapter 4: Gaming as leisure

## Core Idea
Treat play as **designed leisure**: deep fun with start/stop beats doomscroll gaming — session craft matters more than genre.

## Frameworks Introduced
- **Deep Play vs Doomscroll Gaming**: Quality axes (structure, afterglow energy, dopamine liking vs wanting, leisure role)
  - When to use: User says “rest with games” or feels fog after play
  - How: Diagnose mode; add time box + stop rules; cap cheap
- **Session Protocol**: Before / during / after checklist
  - When to use: Every intentional session
  - How: Goal + box + mood match → one title → log line
- **Fun Budget (game slice)**: Deep / Cheap / Relational / Restorative khay
  - When to use: Weekly planning with fun-maxing
  - How: Calendar Deep; timer Cheap; game ≠ restorative
- **Play→Make/Earn hygiene**: Tag Make-research; stream “học” = Follow/cheap; avoid-ship play → 25′ Make first

## Key Concepts
- **Deep fun / cheap fun** (via fun-maxing)
- **Active vs passive leisure** (high-quality leisure)
- **Stop rules**: time/quest end; tilt×2; sleep window; empty-work urge → restorative 10′
- **Afterglow log**: `game | phút | vibe | deep|cheap`

## Mental Models
- Use ranked/grind as deep **if** framed (set count / co-op night).
- Prefer liking over wanting spikes.

## Anti-patterns
- **Infinite queue as rest**: Cap or redesign.
- **Research competitor disguised as chill**: Tag Make-research; protect leisure Next.
- **Borrow sleep for play**: Hard stop.

## Worked Example
Stress + low bandwidth: mood map → cozy/short story; 45′ box; stop at chapter end; log `Hades | 40 | + | deep`. Not: open ranked “for five minutes.”

## Key Takeaways
1. Protocol > genre moralizing.
2. Tie to fun-maxing + dopamine docs when explaining why.
3. Distress lasting → professional care; skill is educational.
