# Chapter 3: Weekly playbook

## Core Idea
Operate Games OS weekly with **capped leverage** — 1–2 priority branches, structured Follow, no mixed-track thrash.

## Frameworks Introduced
- **Weekly Levers**: Minimum viable action per branch with time boxes
  - When to use: Planning a week that includes games
  - How: Pick 1–2 branches; schedule Make deep work; Fix Follow ≤45′
- **End-week Review**: Which branch won? Follow insight actionable? Play over budget?

## Key Concepts
- **Ship-able increment** (Make): lab/feature/design note
- **Fun budget session** (Play): intentional play within cap
- **Career action** (Earn): portfolio/pitch/apply/pricing — 1–2h
- **Weekly brief** (Follow): culture + industry bullets

## Mental Models
- Prefer Follow = structured brief over endless patch-note scroll.
- Separate Make days from Earn days when learning Unity.

## Anti-patterns
- **Scroll patch notes all night, zero ship** → brief + time-box
- **Earn confusion while learning Unity** → split calendar
- **Infinite play as “rest”** → fun budget + fun-maxing
- **Stuff news into tech domain** → keep in `follow/`

## Reference Tables
| Branch | Time | Minimum |
| --- | --- | --- |
| Make | deep work block | 1 ship-able increment |
| Play | fun budget | 1 intentional session |
| Earn | 1–2h | 1 career action |
| Follow | ≤30–45′ | 1 weekly brief |

## Worked Example
Week priority: Make + Play. Daily: if play → one-line log; if make → commit/design bullet before feed. Sunday: review — Follow skipped OK if not scheduled.

## Key Takeaways
1. Do not optimize all four branches every week.
2. Daily light checks beat monthly guilt.
3. Most Follow insights stay `play-only` — that is success.
