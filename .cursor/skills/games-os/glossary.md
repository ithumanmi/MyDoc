# Glossary — Games OS

**Anti-preferences** — Post-session fatigue filters for games you avoid promoting to Next (Ch 5)

**Cheap fun** — Short dopamine spike leisure (idle, infinite queue); must be capped (Ch 4)

**Deep fun / Deep play** — Skill/curiosity/flow play with clear start/stop and good afterglow (Ch 4)

**Earn** — Career/monetization branch → `guides/03-career-skills/game-dev/` (Ch 1–2)

**Earn-signal** — Brief tag: industry note warrants one concrete career/market action (Ch 6)

**Finite Backlog** — Playing / Next / Later / Dropped with hard caps on Playing & Next (Ch 5)

**Follow** — News branch: play-culture + industry radars + weekly brief (Ch 1, 6)

**Four Branches** — Make / Play / Earn / Follow purpose split (Ch 1)

**Fun budget** — Weekly allocation across Deep / Cheap / Relational / Restorative (Ch 4)

**Home genres** — 3–5 genres returned to without FOMO (Ch 5)

**Industry radar** — Charts/policy/publisher/hiring antenna (Ch 6)

**Make** — Build/design/tech branch → `domains/game-dev/` (Ch 1–2)

**Make-research** — Tagged play/research that serves a project; not pure leisure Next (Ch 4–5)

**Mood → genre routing** — Match energy state to open/avoid game types (Ch 5)

**Next** — Committed upcoming titles; cap ≤3 (Ch 5)

**Play** — Leisure branch under `guides/05-games-os/play/` (Ch 1, 4–5)

**Play-culture radar** — Player discourse/taste/community antenna (Ch 6)

**Play-only** — Brief tag: awareness only, no Earn/Make action (Ch 6)

**Playing** — Active titles this week; cap 1–2 (Ch 5)

**Pointer Hub** — Games OS holds IA/map/playbook; deep content linked out (Ch 1)

**Session protocol** — Before/during/after ritual for intentional play (Ch 4)

**Stop rules** — Predetermined end conditions (time, tilt, sleep, empty-work) (Ch 4)

**Weekly levers** — Minimum actions + time boxes per branch (Ch 3)

**Wishlist** — Store catalog; not the same as backlog Next (Ch 5)
