## Core Frameworks & Mental Models

### Four Branches (Make / Play / Earn / Follow)
Use purpose, not “everything game” dump:
- **Make** — build/design/implement → `domains/game-dev/` (+ challenges, mmo-engineering)
- **Earn** — career/freelance/publisher/$ → `guides/03-career-skills/game-dev/`
- **Play** — sustainable leisure, taste, backlog → `guides/05-games-os/play/`
- **Follow** — play-culture + industry news → `guides/05-games-os/follow/`
- “Everything games?” → hub `guides/05-games-os/README.md` → `games-os-map.md`

### Pointer Hub (not content dump)
Like Health OS: hub + map + playbook; **do not copy** Unity/career deep-dives into `05-games-os`. IA / leisure / brief only live here.

### Weekly Leverage Cap
Prefer **1–2 branches/week**. Follow ≤45′. Do not max all four.

### Deep Play vs Doomscroll Gaming
Session design decides quality — not genre alone:
- Deep: start/stop clear, liking after, active leisure
- Doomscroll: infinite queue/FOMO, wanting chase, cheap fun → **cap**

### Session Protocol
Before: 1-sentence goal + time box + mood↔genre. During: one title; tilt → pause 2′. After: `game | phút | vibe | deep|cheap`.

### Fun Budget (game slice)
Deep blocks on calendar · Cheap timer · Relational if needed · Restorative ≠ game. No sleep debt for play.

### Finite Backlog
Playing 1–2 · Next ≤3 · Later · Dropped. Sale → Later. Wishlist ≠ Next.

### Follow Signals with Tags
Brief bullets tagged `play-only` | `earn-signal` | `make-research`. Default action = none. Escalate only with one concrete next step.

### Ranh giới cứng
- No play/news into `domains/game-dev`
- No personal metrics unless asked (`personal/`)
- Educational leisure — not clinical diagnosis
