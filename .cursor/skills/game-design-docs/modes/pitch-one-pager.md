# Mode: Pitch / one-pager

**Job:** Align stake­holders on *why this game exists* and what makes it viable to greenlight next step.  
**Not:** Full GDD, balance sheets, or lore bible.

Template: `domains/game-dev/game-design/templates/game-pitch-one-pager.md`

## Required sections

1. **Hook (1 sentence)** — Fantasy + verb (“You are X doing Y under pressure Z”).
2. **Player & occasion** — Who plays, when, session length target.
3. **Core loop (1 chain)** — `A → B → C → reward` in plain language.
4. **USP / role inversion** — What it flips vs comps (name 1–2 comps).
5. **Pillars (3 max)** — Non‑negotiable experience truths.
6. **Scope slice** — Vertical slice / MVP content boundary.
7. **Business model** — Premium / F2P / GaaS — one line + primary monetization lever.
8. **Risks & asks** — Top 3 risks; what decision/funding/prototype you need next.
9. **Success signals (early)** — Qualitative or measurable — no fake retention %.

## Quality bar

| Do | Don’t |
| --- | --- |
| Fit on ~1–2 pages | Feature laundry list |
| Name comps honestly | “No competition” |
| One clear ask | Multiple conflicting fantasies |
| Pillars testable in play | Marketing adjectives only |
