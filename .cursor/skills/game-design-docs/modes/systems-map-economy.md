# Mode: Systems map / economy model

**Job:** Make loops and currencies **diagrammable and balanceable** — sources, sinks, gates, KPIs.  
**Not:** Full GDD; not monetization rant without tables.

Template: `domains/game-dev/game-design/templates/game-systems-map-economy.md`

## Required sections

1. **Thesis of the economy** — What scarcity / fantasy the economy serves.
2. **Systems map** — Core (in‑session) · Meta (progress) · Live (cadence) — one table or ASCII flow.
3. **Currency taxonomy** — Soft / hard / event / prestige; earn vs buy; persistence.
4. **Source → Sink matrix** — Who produces, who consumes, rates (even if `(assumed)`).
5. **Progression curve** — Level/power vs cost; soft gates; hard walls.
6. **Decision axes in spend** — 1–2 opposing spends (e.g. expand roster vs deepen one kit).
7. **Anti‑inflation & brakes** — Caps, sinks, decay, duplicate protection, pity (if gacha).
8. **Monetization friction map** — Where IAP accelerates; ethical red lines.
9. **Telemetry & KPIs** — Events to log; health metrics (delta/day, sink coverage %).
10. **Open models / spreadsheet todos** — What to simulate next.

## Quality bar

| Do | Don’t |
| --- | --- |
| Every source has a sink path | Currencies with no sink |
| Label assumed rates | Fake live ARPU |
| Separate Core rewards vs Meta sinks | Mix cosmetic shop into combat loop without saying so |
| Name unpaid ceiling | “F2P can get everything easily” without math |
