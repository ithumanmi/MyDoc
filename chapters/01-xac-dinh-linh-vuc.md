### 📊 1. Tự đánh giá trình độ hiện tại

Để biết mình cần đi đâu, trước tiên phải biết mình đang ở đâu. Hãy sử dụng framework này để đánh giá trung thực:

| Level | Đặc điểm nhận dạng | Mental Model |
|---|---|---|
| **Beginner** (0-1 năm) | - Cần hướng dẫn từng bước<br>- Thường copy-paste code mà chưa hiểu sâu<br>- Gặp lỗi là panic, không biết debug | "Làm sao để code chạy được?" |
| **Intermediate** (1-3 năm) | - Tự giải quyết được task thông thường<br>- Biết cách debug và tìm tài liệu<br>- Bắt đầu quan tâm đến clean code | "Làm sao để code tốt hơn, clean hơn?" |
| **Advanced** (3-5 năm) | - Hiểu sâu về architecture và system design<br>- Mentor được cho người khác<br>- Quan tâm đến performance, security, scalability | "Làm sao để hệ thống scale và maintainable?" |
| **Expert** (5+ năm) | - Nhìn thấy vấn đề trước khi nó xảy ra<br>- Đưa ra quyết định kỹ thuật ảnh hưởng toàn dự án<br>- Có tầm nhìn sâu rộng về ngành | "Làm sao để tạo ra giá trị đột phá?" |

**Action:** Xác định bạn đang ở level nào trong lĩnh vực bạn chọn. Đừng tự lừa dối bản thân!

### 📝 3. Đặt mục tiêu SMART cụ thể

Mục tiêu chung chung như "Tôi muốn giỏi AI" sẽ không đưa bạn đến đâu. Hãy dùng **SMART**:

*   **S - Specific (Cụ thể):** Master React Hooks, build Flappy Bird clone, train CNN model.
*   **M - Measurable (Đo lường được):** Xong trong 2 tuần, đạt 90% accuracy, app chạy 60 FPS.
*   **A - Achievable (Khả thi):** Đừng đặt mục tiêu "Build Facebook clone trong 1 tháng" khi mới bắt đầu.
*   **R - Relevant (Liên quan):** Mục tiêu này có phục vụ goal dài hạn không?
*   **T - Time-bound (Có thời hạn):** Deadline rõ ràng (ngày/tháng/năm).

#### **Ví dụ Mục tiêu SMART:**

*   ❌ **Sai:** "Học Unity để làm game."
*   ✅ **Đúng:** "Hoàn thành khóa học Unity 2D cơ bản và publish 1 game Platformer nhỏ lên Itch.io trước ngày 30/12."

*   ❌ **Sai:** "Trở thành chuyên gia AI."
*   ✅ **Đúng:** "Đọc hiểu và implement lại paper 'Attention Is All You Need' bằng PyTorch, đạt kết quả tương đương paper gốc trong vòng 1 tháng."

### 🗺️ 4. Chiến lược phát triển chung

#### **🏆 ONE CORE SKILL Framework - Vũ khí của Top 1%**

**Reality:** Người giỏi Top 1% không cố gắng giỏi đều mọi thứ. Họ có mô hình chữ T:
- **1 Skill lõi cực sâu (Vertical):** World-class level, khó thay thế.
- **Các skill bổ trợ (Horizontal):** Competent level, đủ để làm việc.

**Bài tập xác định CORE SKILL của bạn:**
1. Skill nào bạn tự tin thuộc Top 5% hiện tại?
2. Skill nào bạn có thể nói say sưa 2 tiếng không chán?
3. Skill nào thị trường sẵn sàng trả lương cao/rất cần?
4. **Giao thoa của 3 điều trên = YOUR CORE SKILL.**

**"What gets measured gets managed."** - Bạn cần một dashboard cho bản thân.

**Weekly Tracking Template (Chủ nhật hàng tuần):**
```markdown

**1. Technical KPIs:**
- [ ] Code Quality: ___ PRs merged, Test coverage ___%
- [ ] Deep Work: ___ giờ (Mục tiêu: 15h)
- [ ] Output: ___ features shipped / ___ bugs fixed

**2. Portfolio Progress:**
- [ ] Project [Name]: ___% complete
- [ ] Commits: ___ meaningful commits

**3. Reflection:**
- ✅ Wins (3 điều làm tốt): ___________________
- ❌ Blockers (Điều cản trở): ___________________
```

**Monthly Review (Cuối tháng):**
- 📈 **Trend Analysis:** Kỹ năng nào đang đi lên? Cái nào dậm chân tại chỗ?
- 🔄 **Pivot or Persevere:** Chiến lược hiện tại có hiệu quả không? Cần đổi hướng không?
- 💡 **Core Insight:** Bài học lớn nhất tháng này là gì?

| Tier | Mục tiêu | Loại Project | Đánh giá bằng gì? (Metrics) |

| **Tier 3**<br>(10+ tháng) | **Expertise**<br>Showcase Core Skill | - Custom Game Engine<br>- High-load System<br>- Novel AI Model | - 🚀 Scale (10k+ requests/users)<br>- ⭐ GitHub Stars (>100)<br>- 📄 Case Study chi tiết (Architecture decision) |

### ⚠️ 5. Tránh những sai lầm phổ biến (Anti-Patterns)

1.  **Tutorial Hell:** Xem hết video này đến khóa học khác nhưng không bao giờ tự code cái gì từ đầu.
    *   👉 **Giải pháp:** Xem 1 tutorial -> Tự làm lại (không nhìn code) -> Mở rộng thêm tính năng mới.
2.  **Nhảy việc quá sớm/quá muộn:** Nhảy việc mỗi 6 tháng (red flag) hoặc ở lì 5 năm một chỗ không phát triển (stagnation).
    *   👉 **Giải pháp:** Chỉ chuyển khi học hết những gì có thể hoặc môi trường toxic.
3.  **Bỏ qua nền tảng (Fundamentals):** Lao vào Framework ngay mà không hiểu ngôn ngữ gốc/CS fundamentals.
    *   👉 **Giải pháp:** Master ngôn ngữ trước khi học framework. Học DSA để tư duy logic tốt hơn.
4.  **Ego quá lớn:** Sợ hỏi, sợ sai, giấu dốt.
    *   👉 **Giải pháp:** "Be humble, stay hungry." Chấp nhận mình không biết để học nhanh hơn.

### ⏰ 6. Timeline thực tế (The Reality Check)

Đừng mong thành công sau một đêm. Đây là timeline thực tế của một Top 1% Engineer:

*   **Năm 0-1 (Survival):** Cảm thấy ngu ngốc mỗi ngày. Code toàn bug. Struggle với syntax.
    *   🎯 *Mục tiêu:* Đừng bỏ cuộc. Xây dựng thói quen code hàng ngày.
*   **Năm 1-3 (Growth):** Bắt đầu hiểu chuyện gì đang xảy ra. Tự tin hơn. Có thể mentor người mới.
    *   🎯 *Mục tiêu:* Deep dive vào 1 stack. Xây dựng portfolio chất lượng.
*   **Năm 3-5 (Mastery):** Nhìn code là thấy pattern. Giải quyết vấn đề khó.
    *   🎯 *Mục tiêu:* Học System Design. Lead team nhỏ. Viết blog/chia sẻ kiến thức.
*   **Năm 5+ (Legacy):** Code ít hơn, suy nghĩ nhiều hơn. Mentor thế hệ sau.
    *   🎯 *Mục tiêu:* Trở thành Tech Lead/Architect. Xây dựng Personal Brand.
