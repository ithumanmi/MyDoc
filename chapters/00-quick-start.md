## ⚡ 3 Bước Để Bắt Đầu NGAY (15 phút)

### **Bước 1: Chọn Domain (5 phút)**

Trả lời 3 câu hỏi:

1. **Passion:** Lĩnh vực nào bạn có thể nói chuyện cả ngày không chán?
   - 🎮 Game Development
   - 🤖 AI/Machine Learning
   - 📱 App Development
   - 🌐 Web Development
   - 🛡️ Network & Security
   - 🔗 Blockchain

2. **Skill:** Bạn đang ở level nào?
   - Beginner (0-1 năm)
   - Intermediate (1-3 năm)
   - Advanced (3-5 năm)

3. **Market:** Lĩnh vực này có cơ hội việc làm/kiếm tiền không?
   - ✅ Có nhiều job
   - ✅ Lương cao
   - ✅ Remote-friendly

**→ Viết ra:** "Tôi chọn [Domain] vì [Lý do]"

---

### **Bước 2: Đặt Mục Tiêu SMART (5 phút)**

**Không SMART:**
- ❌ "Tôi muốn giỏi React"
- ❌ "Tôi muốn làm game"

**SMART:**
- ✅ "Tôi sẽ build 1 React Todo App với authentication trong 2 tuần"
- ✅ "Tôi sẽ publish 1 game 2D lên Itch.io trước 31/03"

**Template:**
```
Tôi sẽ [Hành động cụ thể]
để [Kết quả đo lường được]
trước ngày [Deadline rõ ràng]
```

**→ Viết ra mục tiêu của bạn NGAY BÂY GIỜ!**

---

### **Bước 3: Hành Động Đầu Tiên (5 phút)**

**Setup môi trường:**
- [ ] Tạo tài khoản GitHub (nếu chưa có)
- [ ] Cài đặt tools cần thiết (IDE, Git, ...)
- [ ] Join 1 community (Discord/Slack/Facebook Group)

**→ Làm 1 trong 3 việc trên NGAY!**

## 🏃 30-Day Challenge - Tháng đầu tiên

### **Mục tiêu:** Tạo momentum, xây dựng thói quen

### **Week 1: Foundation**

**Daily (2h/day):**
```
Hour 1: Learning
  - Tutorial/Course/Documentation
  - Take notes (viết lại bằng từ của bạn)

Hour 2: Practice
  - Code along với tutorial
  - Modify code (thêm feature mới)
```

**End of Week 1:**
- [ ] Hoàn thành 1 tutorial cơ bản
- [ ] Push code lên GitHub (public repo)
- [ ] Write README (giải thích project làm gì)

---

### **Week 2-3: Build**

**Project:** Choose 1 Tier 1 project (từ [Chapter 1](01-xac-dinh-linh-vuc.md))

**Examples:**
- Todo App (Full CRUD + Auth)
- Weather App (API integration)
- Flappy Bird Clone (Game)
- Simple ML Model (MNIST classifier)

**Daily:**
```
Day 1-2: Planning
  - Sketch UI/Game design
  - List features
  - Setup project structure

Day 3-10: Build
  - 1 feature per day
  - Commit to Git daily
  - Test as you go

Day 11-14: Polish
  - Fix bugs
  - Add styling
  - Deploy (Vercel/Netlify/Itch.io)
```

---

### **Week 4: Share & Reflect**

**Share:**
- [ ] Post project trên community
- [ ] Write blog post về quá trình build
- [ ] Ask for feedback

**Reflect:**
```
What I learned: _________________
What I struggled with: _________________
What I'll do differently: _________________
Next project idea: _________________
```

## 🚨 Common Mistakes - Tránh ngay!

### **❌ Mistake 1: Tutorial Hell**
**Triệu chứng:** Xem tutorial hết cái này đến cái khác nhưng không tự build gì.

**Giải pháp:**
- ✅ Xem 1 tutorial → Build lại KHÔNG nhìn code
- ✅ 70% Learning + 30% Watching

---

### **❌ Mistake 2: No Focus**
**Triệu chứng:** Hôm nay học React, mai học Vue, mốt học Angular.

**Giải pháp:**
- ✅ Chọn 1 tech stack, master nó trước
- ✅ "Depth > Breadth" cho beginner

---

### **❌ Mistake 3: No Tracking**
**Triệu chứng:** Học nhiều nhưng không biết tiến bộ thế nào.

**Giải pháp:**
- ✅ Daily log
- ✅ Weekly review
- ✅ Track giờ deep work

---

### **❌ Mistake 4: Solo Forever**
**Triệu chứng:** Học một mình, không join community, không hỏi ai.

**Giải pháp:**
- ✅ Join 1-2 communities ngay từ đầu
- ✅ Ask questions (đừng sợ!)
- ✅ Help others (teach to learn)

---

### **❌ Mistake 5: Perfectionism**
**Triệu chứng:** Code mãi không ship vì "chưa perfect".

**Giải pháp:**
- ✅ "Done is better than perfect"
- ✅ Ship early, iterate later
- ✅ Version 1.0 được phép xấu!

## 💬 FAQ - Câu hỏi thường gặp

### **Q: Tôi đã 30+ tuổi, còn kịp không?**
**A:** ✅ KỊP! Tech là ngành skill-based, không phải age-based. Nhiều người chuyển ngành thành công ở 30-40 tuổi.

---

### **Q: Tôi không có background IT/CS?**
**A:** ✅ OK! Nhiều developer giỏi self-taught. Background giúp nhưng không bắt buộc.

---

### **Q: Tôi phải học tiếng Anh không?**
**A:** 
- ⚠️ Cần thiết nếu muốn: Remote job, lương cao, tài liệu chất lượng
- ✅ Bắt đầu từ: Đọc documentation, xem tutorial tiếng Anh
- ✅ Improve dần: Grammar không cần perfect, hiểu và giao tiếp được là OK

---

### **Q: Tôi cần bằng cấp không?**
**A:**
- Công ty lớn (Banks, Gov): ⚠️ Có thể yêu cầu
- Startup, tech companies: ✅ Portfolio > Degree
- Freelance/Remote: ✅ Skills only

---

### **Q: Tôi nên học online hay đi bootcamp?**
**A:**

| | Online (Self-taught) | Bootcamp |
|---|---|---|
| **Chi phí** | $0-100/month | $3k-15k |
| **Thời gian** | 6-12+ tháng | 3-6 tháng |
| **Phù hợp** | Self-disciplined | Cần cấu trúc, deadline |
| **Kết quả** | Depend on you | Job placement support |

**Recommendation:** 
- Thử self-taught 3 tháng trước
- Nếu không tiến bộ → Consider bootcamp

---

### **Q: Tôi nên focus 100% học hay vừa học vừa làm?**
**A:**
- ✅ **Best:** Vừa làm vừa học (Apply ngay, có thu nhập)
- ⚠️ **Full-time học:** Nếu có tài chính ổn (3-6 tháng buffer)

---

### **Q: Portfolio phải có bao nhiêu projects?**
**A:**
- Junior: 3-5 projects (Quality > Quantity)
- Mid: 5-7 projects
- Senior: 3-5 projects (Nhưng complex, scale, impact cao)
