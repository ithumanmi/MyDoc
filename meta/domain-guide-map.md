## Decision heuristic

```text
User asks "how do I implement / learn stack X?"
  → domains/<x>/README.md → modules/labs

User asks "salary / freelance / remote / portfolio positioning for X?"
  → guides/03-career-skills/<x>/ (if listed) else career/README.md

User asks both?
  → Open BOTH hubs; lead with domains for skills, guides for monetization.
```
