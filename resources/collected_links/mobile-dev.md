# 📱 Mobile Development Resources

Tuyển chọn công cụ, repo và bài viết giúp tăng tốc học/làm Mobile App (Flutter, React Native, Native).

## 🧱 Frameworks & Starter Kits
- [Flutter Samples](https://github.com/flutter/samples) – Bộ ví dụ chính thức để học UI/State/Animations.
- [Awesome Flutter](https://github.com/Solido/awesome-flutter) – Danh sách thư viện Flutter chất lượng.
- [React Native Directory](https://reactnative.directory/) – Tra cứu packages RN phổ biến.
- [Expo Router Examples](https://github.com/expo/examples) – Mẫu app Expo + Router, phù hợp MVP nhanh.

## 🛠️ Tooling & Productivity
- [Flutter Flavorizr](https://github.com/AngeloAvv/flutter_flavorizr) – Tạo cấu hình nhiều môi trường cho Flutter.
- [Very Good CLI](https://github.com/VeryGoodOpenSource/very_good_cli) – Scaffold + best practices cho Flutter.
- [Ignite CLI](https://github.com/infinitered/ignite) – Generator project React Native.
- [Android Studio Doctor](https://github.com/ravidsrk/android-studio-doctor) – Script kiểm tra nhanh môi trường Android Dev.

## 🔗 Backend & Cloud for Mobile
- [Supabase](https://supabase.com/docs) – BaaS Postgres + Auth, dễ tích hợp Flutter/RN.
- [Firebase Samples](https://github.com/firebase/functions-samples) – Ví dụ Cloud Functions, Auth, Messaging.
- [Appwrite](https://github.com/appwrite/appwrite) – Backend open-source tự host.

## 💰 Monetization & Growth
- [RevenueCat Docs](https://www.revenuecat.com/docs) – Quản lý In-App Purchase, Subscription.
- [Adjust Mobile Measurement](https://www.adjust.com/resources/) – Học attribution, user acquisition.
- [App Store Optimization Guide](https://developers.google.com/learn/topics/app-monetization) – Tổng quan tối ưu ASO.
