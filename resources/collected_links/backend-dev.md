# ⚙️ Backend Development

Danh sách các framework, thư viện và công cụ quan trọng cho phát triển Backend.

## 🏆 Top Rated Repositories

### Languages & Frameworks
*   **Node.js / TypeScript**
    *   [NestJS](https://github.com/nestjs/nest) - Framework Node.js tiến bộ (Progressive), kiến trúc module hóa, hỗ trợ TypeScript tuyệt đối.
    *   [Express](https://github.com/expressjs/express) - Web framework tối giản và linh hoạt nhất cho Node.js.
    *   [Fastify](https://github.com/fastify/fastify) - Web framework tập trung vào hiệu năng cao và overhead thấp.
*   **Python**
    *   [FastAPI](https://github.com/tiangolo/fastapi) - Framework hiện đại, hiệu năng cao để build API với Python 3.8+.
    *   [Django](https://github.com/django/django) - Web framework "pin đi kèm" (batteries-included), bảo mật và mở rộng tốt.
*   **Go (Golang)**
    *   [Gin](https://github.com/gin-gonic/gin) - Web framework viết bằng Go, nhanh hơn Martini 40 lần.
    *   [Fiber](https://github.com/gofiber/fiber) - Web framework lấy cảm hứng từ Express, chạy trên Fasthttp (nhanh nhất cho Go).

### Databases & Cache
*   [PostgreSQL](https://github.com/postgres/postgres) - Cơ sở dữ liệu quan hệ mã nguồn mở mạnh mẽ nhất thế giới.
*   [MongoDB](https://github.com/mongodb/mongo) - Database hướng tài liệu (NoSQL) phổ biến nhất.
*   [Redis](https://github.com/redis/redis) - In-memory data store, dùng làm cache, message broker.
*   [Prisma](https://github.com/prisma/prisma) - ORM thế hệ mới cho Node.js và TypeScript.

### API & Documentation
*   [Swagger / OpenAPI](https://github.com/swagger-api/swagger-ui) - Công cụ thiết kế, xây dựng và document RESTful APIs.
*   [Postman](https://www.postman.com/) - Platform API development phổ biến nhất (không open source hoàn toàn nhưng là chuẩn mực).
*   [tRPC](https://github.com/trpc/trpc) - End-to-end typesafe APIs mà không cần build schemas (cho TypeScript).

### DevOps & Tools
*   [Docker](https://github.com/docker/cli) - Nền tảng container hóa ứng dụng số 1.
*   [Kubernetes](https://github.com/kubernetes/kubernetes) - Hệ thống điều phối container (Orchestration) cấp độ production.
*   [Nginx](https://github.com/nginx/nginx) - HTTP và reverse proxy server hiệu năng cao.

### Architecture & Patterns
*   [Clean Architecture](https://github.com/mattia-battiston/clean-architecture-example) - Ví dụ và tài nguyên về kiến trúc Clean Architecture.
*   [Microservices Patterns](https://github.com/microservices-patterns/microservices-patterns) - Các mẫu thiết kế cho hệ thống Microservices.
*   [System Design Primer](https://github.com/donnemartin/system-design-primer) - Tài liệu học thiết kế hệ thống quy mô lớn (Must-read).
*   [Awesome System Design Resources](https://github.com/ashishps1/awesome-system-design-resources) - Tổng hợp tài nguyên học System Design chuyên sâu.
*   [System Design](https://github.com/karanpratapsingh/system-design) - Kho bài học System Design theo format video + note chi tiết.
