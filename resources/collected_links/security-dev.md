# 🔐 Security & Ethical Hacking

Danh sách các công cụ, tài liệu và repository quan trọng dành cho lĩnh vực An ninh mạng và Pentest.

## 📚 Learning & Roadmaps
*   [OWASP Top 10](https://owasp.org/www-project-top-ten/) - 10 rủi ro bảo mật ứng dụng web phổ biến nhất (Tiêu chuẩn ngành).
*   [Hacker Roadmap](https://github.com/s4n7h0/Hacker-Roadmap) - Lộ trình học tập để trở thành một Penetration Tester.
*   [Awesome Hacking](https://github.com/carpedm20/awesome-hacking) - Danh sách khổng lồ các tài nguyên hacking.
*   [The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) - Tổng hợp các kiến thức, công cụ, one-liners ít người biết.

## 🛠️ Tools & Scanners
*   [Nmap](https://github.com/nmap/nmap) - Công cụ quét mạng và kiểm tra bảo mật (Network Mapper) huyền thoại.
*   [Wireshark](https://github.com/wireshark/wireshark) - Phân tích giao thức mạng (Network Protocol Analyzer) số 1 thế giới.
*   [Metasploit Framework](https://github.com/rapid7/metasploit-framework) - Nền tảng phát triển, kiểm thử và khai thác lỗ hổng bảo mật.
*   [SQLMap](https://github.com/sqlmapproject/sqlmap) - Công cụ tự động phát hiện và khai thác lỗi SQL Injection.
*   [Burp Suite (Community)](https://portswigger.net/burp/communitydownload) - Bộ công cụ kiểm thử bảo mật ứng dụng web (Proxy, Scanner, Intruder...).

## 🎯 Vulnerable Labs (Luyện tập)
*   [OWASP Juice Shop](https://github.com/juice-shop/juice-shop) - Ứng dụng web hiện đại chứa đầy lỗ hổng bảo mật để luyện tập.
*   [DVWA (Damn Vulnerable Web App)](https://github.com/digininja/DVWA) - Ứng dụng PHP/MySQL chứa các lỗi bảo mật web kinh điển.
*   [Metasploitable3](https://github.com/rapid7/metasploitable3) - Máy ảo chứa nhiều lỗ hổng để luyện tập khai thác với Metasploit.

## 📝 Cheat Sheets & Wordlists
*   [PayloadAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Kho tàng payload và bypass cho Web Hacking.
*   [SecLists](https://github.com/danielmiessler/SecLists) - Bộ sưu tập username, password, URL, pattern... dùng cho fuzzing và brute-force.
*   [Reverse Shell Cheat Sheet](https://github.com/swisskyrepo/PayloadsAllTheThings/blob/master/Methodology%20and%20Resources/Reverse%20Shell%20Cheatsheet.md) - Các lệnh tạo reverse shell trên nhiều ngôn ngữ.

## 🔑 Cryptography
*   [OpenSSL](https://github.com/openssl/openssl) - Thư viện mã nguồn mở cho TLS/SSL và các thuật toán mã hóa.
*   [CyberChef](https://github.com/gchq/CyberChef) - "Dao đa năng" cho các thao tác mã hóa, giải mã, chuyển đổi dữ liệu trên web.
