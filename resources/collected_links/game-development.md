# 🎮 Game Development

Các công cụ, nền tảng và tài nguyên hỗ trợ phát triển game, bao gồm cả AI-powered tools.

## 🏆 Top Rated Game Dev Repositories

### Open Source Engines
*   [Godot Engine](https://github.com/godotengine/godot) - Game engine mã nguồn mở đa nền tảng, nhẹ và mạnh mẽ (thay thế tốt cho Unity/Unreal).
*   [Bevy](https://github.com/bevyengine/bevy) - Game engine được xây dựng bằng Rust, kiến trúc Data-Driven (ECS) hiện đại.
*   [Cocos2d-x](https://github.com/cocos2d/cocos2d-x) - Framework làm game C++ cross-platform nổi tiếng cho mobile game.

### Libraries & Frameworks
*   [LibGDX](https://github.com/libgdx/libgdx) - Java Game Development Framework, cực kỳ phổ biến cho Android/Desktop game.
*   [Phaser](https://github.com/phaserjs/phaser) - HTML5 Game Framework tốt nhất để làm game trên trình duyệt (JS/TypeScript).
*   [MonoGame](https://github.com/MonoGame/MonoGame) - Framework C# mạnh mẽ (kế thừa XNA), dùng bởi Stardew Valley, Celeste.

### Tools & Utilities
*   [Blender](https://github.com/blender/blender) - Phần mềm 3D open-source toàn diện (Modeling, Rigging, Animation, Rendering).
*   [Tiled](https://github.com/mapeditor/tiled) - Trình biên tập bản đồ (Tile Map Editor) 2D linh hoạt nhất.
*   [Pixelorama](https://github.com/Orama-Interactive/Pixelorama) - Công cụ vẽ Pixel Art mã nguồn mở miễn phí.

### Learning & Resources
*   [Awesome Game Development](https://github.com/ellisonleao/magictools) - Danh sách khổng lồ các tài nguyên, công cụ làm game.
*   [Game Programming Patterns](https://github.com/munificent/game-programming-patterns) - Sách kinh điển về các mẫu thiết kế trong lập trình game (có bản web miễn phí).

## 🎮 Top Unity Repositories

### Frameworks & Architecture
*   [Zenject](https://github.com/modesttree/Zenject) - Dependency Injection (DI) Framework mạnh mẽ nhất cho Unity (nay là Extenject).
*   [UniRx](https://github.com/neuecc/UniRx) - Reactive Extensions (Rx) cho Unity, giúp xử lý asynchronous và event dễ dàng.
*   [Entitas](https://github.com/sschmid/Entitas-CSharp) - Entity Component System (ECS) Framework siêu nhanh cho C# và Unity.

### Tools & Utilities
*   [Odin Inspector](https://odininspector.com/) - (Commercial/Plugin) Công cụ mở rộng Editor cực mạnh, giúp custom inspector dễ dàng (repo tham khảo: [Odin-Serializer](https://github.com/TeamSirenix/odin-serializer)).
*   [DOTween](https://github.com/Demigiant/dotween) - Engine animation nhanh và nhẹ nhất cho Unity (scripting).
*   [NaughtyAttributes](https://github.com/dbrizov/NaughtyAttributes) - Bộ attribute mở rộng cho Inspector mà không cần viết Custom Editor.

### Networking
*   [Mirror](https://github.com/MirrorNetworking/Mirror) - Giải pháp Networking mã nguồn mở thay thế UNET, cộng đồng lớn.
*   [FishNet](https://github.com/FirstGearGames/FishNet) - Networking solution hiện đại, hiệu năng cao và feature-rich.

### Learning & Source Code
*   [Unity CsReference](https://github.com/Unity-Technologies/UnityCsReference) - Mã nguồn C# tham khảo của Unity Engine (để hiểu sâu cách Unity hoạt động).
*   [Awesome Unity](https://github.com/RyanNielson/awesome-unity) - Danh sách tài nguyên Unity được tuyển chọn kỹ lưỡng.

## 🛠️ Essential Unity Utilities & Helpers

Các công cụ nhỏ nhưng "có võ", giúp tăng tốc workflow đáng kể.

### Workflow & Editor
*   [Unity Toolbar Extender](https://github.com/marijnz/unity-toolbar-extender) - Cho phép thêm các nút custom vào thanh Toolbar chính của Unity.
*   [Rainbow Folders 2](https://github.com/PhannGor/unity-rainbow-folders) - (Hoặc tương tự) Giúp tô màu folder trong Project view để dễ quản lý.
*   [Eflatun.SceneReference](https://github.com/starikcetin/Eflatun.SceneReference) - Giải pháp an toàn (type-safe) để tham chiếu Scene, tránh dùng string dễ lỗi.

### Graphics & Visuals
*   [Keijiro Repositories](https://github.com/keijiro) - Kho tàng các hiệu ứng visual, shader, VFX Graph đỉnh cao của Keijiro Takahashi (Unity Technologies).
*   [Unity URP/HDRP Demos](https://github.com/Unity-Technologies) - Các project mẫu chính chủ của Unity (Boat Attack, Fontainebleau) để học về Graphics.

### Coding Helpers
*   [UniTask](https://github.com/Cysharp/UniTask) - Thư viện `async/await` allocation-free, hiệu năng cao dành riêng cho Unity (thay thế Coroutine).
*   [Serilog-Unity](https://github.com/K775/serilog-sinks-unity3d) - (Hoặc các lib logging tương tự) Giúp log thông minh và có cấu trúc hơn `Debug.Log`.

### Save System
*   [Easy Save](https://assetstore.unity.com/packages/tools/input-management/easy-save-the-complete-save-data-serializer-system-768) - (Asset Store) Giải pháp save game phổ biến nhất (trả phí).
*   [Save System for Unity](https://github.com/BayatGames/SaveSystem) - (Free alternative) Hệ thống lưu trữ dữ liệu json/binary đơn giản, dễ dùng.

## 🧠 AI for Game
*   [Unity-MCP](https://github.com/IvanMurzak/Unity-MCP) - Cầu nối kết nối Unity Editor với các LLM/Agents thông qua Model Context Protocol (MCP).
*   [Unity ML-Agents](https://github.com/Unity-Technologies/ml-agents) - Toolkit mã nguồn mở của Unity giúp huấn luyện agents bằng Reinforcement Learning.
*   [Ludo.ai](https://ludo.ai/) - AI hỗ trợ tìm ý tưởng game, concept art và nghiên cứu thị trường.
*   [NVIDIA ACE for Games](https://developer.nvidia.com/ace-for-games) - Avatar Cloud Engine: Tạo nhân vật NPC thông minh với AI.
*   [Meshy.ai](https://www.meshy.ai/) - Tạo 3D assets từ text/image bằng AI.
*   [Cascadeur](https://cascadeur.com/) - Phần mềm AI hỗ trợ làm animation vật lý chính xác.

## 🛠️ Engines & Frameworks (Others)
*   [Colyseus](https://colyseus.io/) - Multiplayer Game Server framework (Node.js/TypeScript).
*   [Twinery](https://twinery.org/) - Công cụ mã nguồn mở để viết các câu chuyện tương tác (Interactive Fiction), game text-based.
*   [DinhKarate Game/AI Projects](https://github.com/dinhkarate/) - Repo cá nhân chứa nhiều thử nghiệm về game AI, agent và automation.
*   [Open Source Indie Tools](https://www.reddit.com/r/indiegames/) - Cộng đồng chia sẻ công cụ, bài học tài chính và marketing cho game độc lập.
