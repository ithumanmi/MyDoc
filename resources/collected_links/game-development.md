## Commercial / SaaS tools

*   [Odin Inspector](https://odininspector.com/) - Unity Editor toolkit (trả phí). Serializer OSS nằm ở PROJECTS.
*   [Easy Save](https://assetstore.unity.com/packages/tools/input-management/easy-save-the-complete-save-data-serializer-system-768) - Save system Asset Store.
*   [Ludo.ai](https://ludo.ai/) - AI concept / market research cho game.
*   [NVIDIA ACE for Games](https://developer.nvidia.com/ace-for-games) - NPC / avatar AI.
*   [Meshy.ai](https://www.meshy.ai/) - Text/image → 3D assets.
*   [Cascadeur](https://cascadeur.com/) - Animation physics AI.
*   [Colyseus](https://colyseus.io/) - Multiplayer game server (Node/TS).
*   [Twinery](https://twinery.org/) - Interactive fiction / text games.
